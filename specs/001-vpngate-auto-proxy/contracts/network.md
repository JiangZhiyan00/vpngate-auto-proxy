# 网络、权限与生命周期契约

T098 将公开状态和停止监听器作为特权父进程创建的实例资源，通过继承描述符交给身份核验后的低权限控制进程。停止须显式请求特权候选池关闭并等待直属进程回收，之后才可按设备号与节点号清理控制套接字、实例锁和目录；未知或替换节点必须保留并失败。当前既有目录拒绝接管，持久崩溃恢复另行实现，见[记录](../../../docs/validation/macos-public-instance.md)。

T094 内部控制协议只接受部署方私有交付的已连接通道，固定授权、版本及递增序号；客户端核对响应操作与工作归属，超时或取消执行中的请求后关闭连接。特权侧保留成功检测凭据，提升再次复核并启动独立健康；账户、依赖、目录与预算不由控制请求修改。操作中仍观察断开或重叠请求，故障后取消并等待所属回收。协议不代替实际控制进程启动与身份核验，不提供异步状态推送，控制主服务仍须接入状态及本地网关撤销，见[记录](../../../docs/validation/macos-control-channel.md)。

T093 活动健康调度独立于候选建立及检测，仅当前活动代际可创建一个调度所有者。健康会话全程占用回收登记，不复制控制句柄；停止先撤销再等待会话与各直属检测回收，禁止停止后派生。检测失败或监督异常先撤销旧代际，再发布关联代际的结果；撤销后迟到成功不得发布。丢弃等待不会中止回收，未知回收继续保留候选槽位；公共主服务和原生验收仍未完成，见[记录](../../../docs/validation/macos-active-health.md)。

T092 正常调用链验证入口要求明确选定节点与输入摘要；先核验全部所选材料，再经正式代际及低权限出口检测提升活动出口。保留最多两个并存候选，每个候选建立和退休后复核活动引用及出口检测。失败保留阶段报告，取消后持续所属回收；接口名称与索引清单相等不等价于宿主完整路由解析基线，网页检测成功不等价于出口身份、持续连接或零直连。原生尚未执行，完整后端及公共服务标志保持假，见[工具记录](../../../docs/validation/macos-native-pipeline.md)。

联合监督须同时持有直属隧道和业务子进程；任一进程或管理故障必须进入两侧停止与回收。正常返回必须确认业务退休、控制句柄释放及两类进程实际退出，任一阶段失败仍尝试后续回收并保留各阶段错误。监督任务取消不能等同于已完成异步回收；完整服务崩溃后的归属核对与安全恢复仍须独立验收。T076 已完成上述组合的普通权限子进程回归，尚未接入正式运行入口。

## 苹果接口拓扑材料约束

必须由已认证的直属管理会话接收一次完整启停环境帧，必要字段唯一，区分虚拟点对点对端与子网掩码，不把承载远端用作虚拟对端。名称须匹配实际控制句柄，本地地址须匹配连接状态，承载远端须匹配授权地址；开始与交付前均再次核对句柄。完整通知与连接状态齐备前保持总启动截止及累计输出上限。环境帧不得夹入其他记录，缺失、冲突、重复、关闭、重连及超限均拒绝并撤销。未使用环境值不保存到材料或日志，错误不回显原始内容。

材料交付必须继续持有真实句柄及同一撤销令牌，已撤销材料不得拆出用于配置；交接后配置和后续生命周期仍由该令牌监督。材料不是配置成功或出口验证结果。T081 的普通权限解析、会话及归属回归已完成；正式通知开关、父进程接入、地址配置及真实隧道通知尚未验收。

地址配置仅接受仍持有真实控制句柄的认证材料；真实与有效管理员身份前置，进程内串行执行固定系统调用。每步前及结果核验后检查同一撤销令牌与句柄身份；拒绝本次接口已有地址、外部地址范围或目的地址冲突。只有仍存活且内核唯一地址、对端、掩码和启用状态一致的项目材料才可授权同地址并存；材料数量有界且拒绝重复索引。配置后再次核对地址、拓扑、最大传输单元及启用标志，错误撤销会话并保留调用方句柄，先回收消费者再释放；不得按名称覆盖式回滚。T082 已完成组件与普通权限回归，真实写入、隐式路由影响和正式接入尚未验收。

通知模式与严格材料入口必须成对选择，旧联合监督拒绝通知模式也须回收两侧。直属配置监督保留原始句柄，完整认证材料后调用地址配置，配置返回后重新轮询管理、进程、停止及截止，先处理已到达故障再交付材料；交付后继续监督同一令牌。丢弃未交接的配置材料撤销会话；有效拆出保持原令牌，过期拆出拒绝。并存复制件必须再次核验真实身份并沿用原撤销令牌，配置结束后释放。失败保留原件及未交付材料至直属回收尝试结束；取消仍不冒充等待成功。T083 已完成平台入口串联与普通回归，公共服务、完整路由及管理员原生写入仍待验收。

## 苹果隧道串行启动约束

特权启动桥接必须在异步运行时及其他线程创建前运行；先核验管理员保护的依赖记录、程序摘要、非系统动态库加载路径、私有配置及管理端点，再通过私有通道核对真实控制句柄身份。仅最后一步允许本次句柄跨执行替换继承；成功保持原进程号，失败直接退出独立启动进程，不重试或回到公共服务。不得继承任意加载、加密配置或模块搜索环境。

## 苹果直属隧道父进程约束

父进程只能启动同一项目程序的隐藏串行入口，不接受外部可执行覆盖或任意参数。公开启动入口要求真实与有效管理员身份、管理员保护的项目程序与材料路径、0700 管理目录；每次独立创建 0600 管理端点。真实句柄核验后须设置执行时关闭标志，父方复制时还须保护保留原件，不能只保护复制件。控制句柄通过本次专属通道交接，父方本次复制件在发送后关闭。管理连接必须核对仍直接持有的子进程对象及内核对端身份；启动失败、超时和取消须进入有界回收，不得仅返回裸进程号。

联合监督接入须核对业务与隧道接口一致，沿用隧道原有授权远端及用户；接入被拒绝也须尝试并等待两侧清理。端点归属随直属子进程移交，正常停止确认双进程回收后才确认端点清理；路径被替换时拒绝删除。析构取消只能触发关闭与终止，不能冒充异步回收成功。T078 的普通权限组件回归已完成，真实接口创建配置、管理员安装及完整服务仍未接通。

## 苹果控制接口创建约束

特权父进程须先检查真实与有效管理员身份，再读取接口清单并创建本次控制连接。固定控制器名称，在有限范围请求明确单元，只跳过连接阶段明确占用；不得接管既有接口、推导接口名称或索引，也不得把控制器查询错误当占用。创建期间不得并发派生子进程，连接前设置执行继承保护。名称、索引及初始状态须从内核与真实句柄交叉核对，拒绝既有名称或索引、非点对点、回环及已有四版地址的资源。失败仅关闭本次句柄，不按名称销毁未知接口。

管理状态的承载远端不能当作虚拟接口对端。配置前须取得并校验完整拓扑、地址和掩码材料，再与本次句柄及已认证管理会话核对。T080 已完成创建组件、再核验和原生诊断工具准备；管理员实际创建、地址配置、正式接入及完整原生故障验收仍待 T057。

## 苹果固定依赖安装约束

依赖材料只能由普通用户构建、由管理员显式选择安装；摘要核验不充当构建认证或发布签名。安装必须先有界读取完整快照，核对固定源码与补丁、全部文件摘要、许可材料和系统动态库限制，再写入受保护目录；不得以管理员身份运行候选、编译器或归档脚本。先同步私有暂存材料及最终启动记录，再原子不覆盖提交；既有目录、文件、符号链接及并发安装不得被覆盖，失败只清理本次归属暂存。

安装成功不自动激活服务或更改网络。独立静态候选必须重新完成真实隧道及两种承载验收，不能沿用旧动态链接程序的原生结论。T079 的普通权限组件和候选兼容回归已完成，管理员实际安装、主程序保护部署与原生整体仍待 T057。

## 苹果索引复用的已验证约束

2026-10-12 原生实验确认：不同远端身份的接口复用旧数字索引后，使用旧索引建立的新连接可抵达新远端，见[证据](../../../docs/validation/macos-index-reuse.json)。接口名称和数字索引都不能单独作为持久出口身份。此处只确定安全约束，完整苹果后端方案仍待 T057 收口。

后端必须使旧工作进程引用在撤销后无法用于新代际；在受控停止路径中，旧业务进程及连接完全回收后才能释放接口供重建。还须覆盖接口异常消失、外部重建及检查与连接之间的竞争，不能仅通过连接前查询索引存在来宣称安全。以上机制需要独立实现和验证；当前 `index_reuse_isolation_validated` 为假。

2026-10-12 异常终止实验进一步确认：旧接口索引被不同远端实际复用后，仍存活的原数据报套接字收到替代远端响应，见[原生证据](../../../docs/validation/macos-abrupt-native.json)。这表明只给新请求检查代际、只等待正常撤销或只绑定接口，均不足以覆盖异常退出后的旧套接字。苹果后端必须在异常接口释放与外部重建竞争中，对已有业务及解析套接字提供独立阻断，并通过真实场景验证；不能将定时检查或异步通知本身当作无竞争保证。原流式套接字本次无响应不证明其在所有故障条件下安全。完整方案尚未确定，现有原型不得接入生产。

## 流量与隔离边界

```text
局域网设备 → 映射端口 → 入口认证与配额 → 路径型 Unix 套接字
                                              ↓
                                  活动工作进程私有网络空间
                                     DNS / 目标连接 → tun0 → VPN

候选验证器 → 候选私有 Unix 套接字 → 候选网络空间 → 候选 tun0
控制进程 → 容器管理网络 → 节点来源（控制流量）
```

路径型 Unix 套接字共享文件系统目录，不使用被网络空间隔离的抽象套接字。
控制进程与业务工作进程降为 UID/GID 10001；OpenVPN 专用 UID 10002，
特权辅助进程负责创建、销毁及监督网络资源，协议不允许任意命令执行。
套接字目录 `0750`、文件 `0660`；配置私钥目录独立，不向控制进程开放。

默认一个活动加两个临候选；配置并发数 C 时总工作槽上限 C+1。
候选和活动分别使用独立地址段、路由、DNS、隧道与私有套接字。
分配地址前检查现有路由冲突，使用实例标识标记专属资源；无法分配时明确失败。

## 无上游的直接连接

每个工作进程仅有一个固定节点 `{public_ipv4, port, transport}`；TCP 与 UDP 都可承载 OpenVPN。
配置解析区分顶层协议与 remote 行协议，拒绝多个远端和矛盾配置；缺省协议按 OpenVPN UDP 规则归一化。
远端必须与来源节点 IPv4 一致，禁止远端主机名、代理覆盖及运行时任意替换。

节点 `/32` 路由经虚拟网卡管理网关，优先于隧道两条 `/1` 路由；
OpenVPN 封装连接不会进入自身隧道。隧道覆盖完整 IPv4 空间后仍由默认拒绝规则兜底。
忽略服务端推送路由与 DNS，由辅助进程安装本地受控路由。
根空间只为已分配工作网段在实际外联网卡上做源地址转换，原生与容器均使用本实例专用表。
不改宿主默认路由、域名解析或现有防火墙规则；原生只添加本实例专用资源，
不设置宿主全局转发默认拒绝，也不自动改写宿主 `net.ipv4.ip_forward`。
原生启动检查已有 IPv4 转发值与可用转发路径，缺少前提时明确报告；
部署者预配置转发及现有防火墙的窄范围允许规则，不以自动关闭防火墙替代。
本项目表内的允许规则不能覆盖其他基础链的拒绝动作；已有转发过滤必须纳入部署验收。

## 防直连规则

工作空间输出默认拒绝，只允许回环、业务经 `tun0`，以及 OpenVPN 专用用户经虚拟网卡
访问固定节点 IP、端口和承载协议。普通业务用户即使请求相同节点地址也不能走管理路径。
工作空间输入仅允许已建立关联流量和必要的本地管理流量。

容器根空间的本项目转发路径按工作网卡、源地址和节点端点精确放行；
原生以本项目虚拟网卡为作用域设置规则，不改变其他转发链策略。
入站回程仅放行对应已建立关联流量，未匹配的本项目工作流量拒绝。
不能照搬原核心只放行上游地址的护栏，也不能为移除上游而删除全部护栏。

业务与检测 DNS 只在工作空间发送，经隧道使用有界解析客户端；
禁用工作空间 IPv6并用防火墙拒绝 IPv6。控制来源 DNS 可以使用容器/宿主管理网络。
检测及跳转不得使用宿主 resolver 或自动环境代理；桥接只通向指定工作进程。

## 不可信配置

沿用白名单解析并重新生成配置，拒绝脚本、插件、外部文件、附加管理接口、额外远端、
未经允许的路由和代理设置。只保留必要内联证书与密码学参数。
强制安全脚本级别、私有管理套接字和推送过滤；不能只净化下载文件却接受服务端任意推送。
本地固定每五秒发送隧道空闲保活，继续过滤远端推送的保活参数；保活不构成业务连接的空闲超时。
不为兼容失败节点自动放宽 TLS、启用旧算法或压缩；不支持的配置记录为拒绝，不冒充离线。

## 发布、故障与取消

握手、管理状态及完整路由都就绪后才验证出口；出口通过前不能发布活动引用。
后台候选检测不修改当前活动引用，检测完成后释放资源；之后启用对应节点时重新建隧道、重新验证。
首次启动或故障恢复创建的待启用隧道，在本次实际出口验证成功后直接提升为活动出口，
不先销毁再重建，不重复做同一次启用验证。待启用隧道占候选槽，提升后转为唯一活动槽；
失败则清理后尝试下一节点，仍遵守轮次与并发配额。
每秒复用结构性隧道检查；发现进程、路由或接口消失即阻断，不等待周期 HTTP 检测。
HTTP 一次检测全部失败或总超时后先清空活动引用、取消旧连接，再开始替代连接。
检测失败到阻断不跨下一个检测周期；禁止旧连接排空后继续访问已失效出口。

## Docker 契约

首版支持 Linux 上有根 Docker，桥接网络，显式发布代理端口和传入只读配置/凭据。
不使用 `privileged`、宿主网络、Docker 套接字或宿主命名空间挂载。
挂载 `/dev/net/tun`；只读根文件系统，可写 `/run` 与 `/tmp`，持久化数据卷。

沿用固定核心所需能力，先删除全部能力，再按用途添加：

| 能力 | 用途 |
| --- | --- |
| `NET_ADMIN` | 工作网卡、隧道、路由及防火墙 |
| `SYS_ADMIN` | 网络空间创建、切换、绑定及私有挂载 |
| `SETUID`、`SETGID`、`SETPCAP` | 降权与收缩能力 |
| `KILL` | 跨用户停止本实例子进程 |
| `CHOWN`、`DAC_OVERRIDE`、`FOWNER` | 初始化私有目录和归属，沿用核心后按实测缩减 |

启用 `no-new-privileges`，保留默认 seccomp；OpenVPN 仅保留网络管理需要的能力，
主控制与工作进程清空能力。特权集中于网络辅助进程，不授予入口任意网络管理接口。

启用 AppArmor 的主机须加载本项目专用 profile，放行容器内命名空间绑定挂载、
私有临时 proc 挂载及所需路径访问，其他约束继承默认配置的防护意图。
profile 必须覆盖本项目命名空间绑定/传播设置/卸载和私有临时 procfs 挂载；
不能保留无条件禁止挂载规则再追加允许，因为显式禁止优先。
不修改 Docker 全局默认 profile，不默认设为不受约束模式。
没有权限或安全配置阻止所需操作时，启动明确失败，不提示用户关闭宿主防护。
profile 文件和实际能力集在实施阶段交付并验证，当前设计未运行证明。

## 退出与遗留清理

停止时清空活动引用 → 停止入口 → 取消调度和转发 → 并行终止工作进程组 →
回收子进程 → 删除本实例虚拟网卡/规则/命名空间绑定 → 清理运行目录。
默认内部总预算 12 秒、外部总预算 15 秒；不能为每个工作进程各等待 15 秒。
终止宽限后强制结束本实例进程，不能仅删除命名空间名称却保留持有它的进程。

原生启动锁定实例并校验资源清单与进程启动身份，只处理本实例确认遗留；
无法证明归属则拒绝启动。容器内资源与 PID/网络空间私有，退出后不遗留宿主命名空间资源。
无论恢复或替换容器，只恢复来源缓存，不恢复任何活动出口就绪状态。

## 苹果私有启动交接原型约束

T073 内部工作进程监督确认采用四十字节固定帧，就绪/退休版本分别为 `VWR1`/`VWT1`，随后依次为十六字节授权标识、十六字节代际和四字节大端接口索引。就绪须晚于真实句柄核验及私有监听建立，退休须晚于登记资源、句柄及监听清理。发送和完整接收采用三秒总截止；监督方核对授权、非零代际、索引，退休还须核对原就绪代际。控制通道关闭、读取错误或任何输入都撤销代际。就绪不能替代实际出口验证，退休不能替代进程退出回收；正式监督与原生路由验收仍待完成，见[验证记录](../../../docs/validation/macos-worker-control.md)。

2026-10-12，T068 增加独立受控工作进程的私有启动交接。可信父进程提供专属套接字对，接收方核对固定版本、授权标识、接口索引及恰好一个描述符后才发布就绪。元数据不能替代句柄来源、真实隧道身份及对端授权校验。接收阶段串行执行，不并发派生其他程序；任何错误、截断或超时都必须退出该独立进程，不允许回退或继续接纳。苹果截断交接可能存在内核已安装但用户空间未获编号的描述符，仅退出进程才能保证其回收；此入口不得用于长驻网络辅助进程。正常退休沿用先释放登记网络操作、再关闭持有句柄的顺序。验证及限定范围见[交接记录](../../../docs/validation/macos-custody-transfer.md)，完整后端尚未通过。


## 苹果真实控制句柄身份增量

正式苹果后端的代理业务和解析必须只通过已核验隧道身份的代际网络入口；隧道身份丢失、代际撤销或进程退出后，停止接纳和转发，恢复前重新建立并验证出口。受控实验的按接口限定主机路由只覆盖该目标，任意公网目标的路由方式、清理归属及异常重启仍须独立实现和原生验证。不得把全局报文过滤规则当作产品唯一阻断边界；苹果[技术说明 TN3165](https://developer.apple.com/documentation/technotes/tn3165-packet-filter-is-not-api)指出它不是面向广泛分发产品的应用接口。
