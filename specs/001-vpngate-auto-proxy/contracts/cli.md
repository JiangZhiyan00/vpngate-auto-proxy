# 命令行与状态契约

这是实施后必须满足的接口，不表示当前仓库已有可运行程序。命令名为 `vpngate-auto-proxy`。
默认人类输出为简体中文，时间按实例配置时区显示，默认上海；机器输出时间仍使用 UTC，新增 timezone 字段表示实例显示时区。旧状态缺少该字段时默认上海。
不提供网页、管理 TCP 端口或远程停止接口。

## 原生交付范围

苹果系统与 Linux 分别构建本项目的单个可执行文件，提供相同的用户命令；允许预先安装外部隧道程序和必要系统工具。单文件交付不表示跨系统共用同一个二进制文件，也不表示无运行依赖。内部子进程由同一可执行文件的隐藏子命令启动；苹果系统原生支持须有独立网络后端及验收证据。

## 命令

| 命令 | 行为 |
| --- | --- |
| `--help`、`--version` | 无须特权，不连接网络 |
| `run --config PATH` | 前台运行；检查配置、权限、依赖、端口；初始化后持续服务 |
| `status --runtime-dir PATH` | 查询本地控制套接字，显示运行状态 |
| `status --runtime-dir PATH --json` | 标准输出一个 JSON 对象，不混入日志 |
| `status --runtime-dir PATH --check-ready` | 已就绪返回 0；未就绪返回 3；不发起额外外网检测 |
| `stop --runtime-dir PATH` | 请求正常停止并等待资源回收，不向不明 pid 发信号 |

不要求后台守护命令；原生由用户前台启动或外部服务管理器托管，容器由 PID 1 转发信号。
内部网络辅助和工作进程子命令不作为用户接口，不接受未经授权的任意命令或文件路径。

## 退出与信号

- 0：命令完成；正常停止的运行进程也返回 0。
- 1：运行或控制通信失败；错误说明写标准错误。
- 2：配置或参数无效。
- 3：`--check-ready` 检查未就绪；其他状态查看仍可返回 0 并显示等待原因。
- 4：停止超时或资源清理失败，输出所属资源与具体原因。

收到 SIGINT/SIGTERM 等同本地停止。默认 12 秒内部清理截止，15 秒内退出。
全部节点不可用只改变服务状态，保持运行并退避，不以等待时间作为退出条件。
重复 stop 对已停止实例幂等；无法证明属于该实例的进程不终止。

## 控制套接字与状态字段

路径为运行目录下 `control.sock`，父目录仅属主/管理组可访问，套接字权限 `0660`。
控制协议版本 1；单帧 UTF-8 JSON，4 字节大端长度，最大 64 KiB，5 秒读写超时。
仅支持 `status`、`stop` 两种操作；拒绝未知字段、版本和超长帧。
停止命令先确认已受理，再由客户端轮询状态至退出，不能被 5 秒读写时限截断清理。
特权 `netd.sock` 与用户控制套接字分离，复用原核心有界类型化协议，不暴露任意 shell 执行。

状态 JSON 至少包含：

| 字段 | 含义 |
| --- | --- |
| `schema_version`、`instance_id` | 版本与实例归属 |
| `state` | starting、fetching、validating、ready、waiting、switching、stopping、stopped |
| `ready` | 是否允许业务转发；不能只由进程存活推导 |
| `timezone` | 实例 IANA 显示时区；机器时间字段仍为 UTC，新版客户端读取旧消息缺字段时默认上海 |
| `listen_address` | 实际监听地址，不含用户名密码 |
| `active_node` | 节点 id、公开端点、承载协议；无活动出口为 null |
| `last_exit_check` | 完成时间、尝试次数、结果、耗时和失败分类 |
| `source` | 最近获取时间、缓存年龄、是否过期、最近刷新错误 |
| `candidates` | 总数、可用/过期/未检测数、本轮进度、活动检测数、下次调度时间 |
| `connections` | 当前占用和上限 |
| `last_switch_reason`、`last_error` | 中文说明与稳定错误分类 |

状态中禁止包含秘密配置、凭据、证书、业务目的地址或访问正文。
默认容器健康检查查询进程与本地控制套接字存活，不因无节点自动杀进程；
是否能提供代理由 `ready` 和显式 `--check-ready` 表达，避免重启风暴。

## SOCKS5 契约

默认 IPv4 回环 `127.0.0.1:1080`；局域网显式绑定并要求用户名密码方法。
回环未配凭据可用无认证；配置凭据后只接受用户名密码方式。
只提供 CONNECT，支持 IPv4 数字地址或域名；不支持 BIND、UDP ASSOCIATE 和 IPv6。
拒绝回环、私网、链路本地、组播、保留及文档网段等非公网目标；
域名解析后同样校验，不能经域名绕过限制。隧道节点的私有内网地址只用于本地路由管理。

认证失败返回认证失败并关闭；无出口、连接超限、目标不可达等返回适当失败并关闭。
客户端握手及目标连接使用有界时限，默认 10 秒握手、10 秒目标连接；
转发中的已建立连接不因静默自动断开，不新增用户未要求的业务空闲超时。
配额从接受连接起持有；第 51 个拒绝，不挤占前 50 个，失败或断开立即释放。

所有业务 TCP 与域名解析仅由工作进程发起；控制进程不代做目标 DNS。
检测失败或隧道消失时先撤销活动引用，再取消旧转发；旧连接不得转移到新隧道。
