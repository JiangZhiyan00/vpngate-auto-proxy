# 配置契约

## 容器环境适配层（需-022）

仅镜像仓库编排显式设置 `VAP_CONFIG_MODE=environment`；旧 JSON 模式继续为默认。`.env` 的 `VAP_COUNTRIES`、`VAP_TIMEZONE`、`VAP_SOURCE_URL`、`VAP_ALLOW_LEGACY_VPNGATE_CRYPTO`、`VAP_EXIT_CHECK_URLS` 及现有数字配置字段的大写 `VAP_` 名称映射到程序配置。空值采用原默认；列表逗号分隔并去除两侧空白，非空列表不允许空项；布尔严格为 true/false，数字严格为无符号十进制整数，最终复用 AppConfig 校验。

容器固定 `listen=0.0.0.0:1080`、`credentials_file=/run/secrets/proxy_credentials`、`data_dir=/var/lib/vap`、`runtime_dir=/run/vap`。`VAP_PORT` 与 `VAP_BIND_ADDRESS` 仅控制宿主发布。生成的 JSON 不包含凭据内容，仅写入容器临时目录；管理命令不生成配置。修改 `.env` 后执行 `docker compose up -d`，修改独立凭据后重新启动。原生 JSON 入口不读取这些变量。

程序配置使用 UTF-8 JSON，模式版本 1；原生及文件模式使用显式配置文件，重启生效，拒绝未知字段及错误类型。镜像仓库部署按上方适配层仅维护 `.env`，启动时转换为临时 JSON。
配置不支持隐式读取系统代理环境变量。相对文件路径基于配置文件目录解析。

## 字段与默认值

| 字段 | 默认值 | 校验 |
| --- | --- | --- |
| `schema_version` | 1 | 仅接受已支持版本 |
| `listen` | `127.0.0.1:1080` | IPv4 与有效端口，非回环要求凭据 |
| `credentials_file` | 未设置 | 非回环必填；不接受部分用户名密码 |
| `data_dir` | `/var/lib/vpngate-auto-proxy` | 可写私有目录，缓存在此持久化 |
| `runtime_dir` | `/run/vpngate-auto-proxy` | 可写私有临时目录，本机实例独占 |
| `countries` | `[]`（全部） | 最多 256 项；每项两位 ASCII 英文字母，大小写不敏感匹配来源；无匹配不回退 |
| `timezone` | `Asia/Shanghai` | 支持的 IANA 名称；非法名称拒绝；影响日志及人类状态显示，机器时间保持 UTC |
| `source_url` | `https://www.vpngate.net/api/iphone/` | HTTP/HTTPS，禁止内嵌用户名密码 |
| `allow_legacy_vpngate_crypto` | Linux／Docker 为 `true`；苹果原生为 `false` | 仅 Linux 支持固定的完整 `AES-128-CBC`、`SHA1` 旧算法组合；省略或容器空值采用默认，显式 `false` 保持严格模式，其他配置仍按严格白名单处理 |
| `source_refresh_seconds` | 1800 | 正整数 |
| `source_timeout_seconds` | 15 | 正整数 |
| `source_cache_ttl_seconds` | 86400 | 正整数 |
| `candidate_interval_seconds` | 900 | 正整数，启动即开始首轮 |
| `candidate_result_ttl_seconds` | 900 | 正整数 |
| `candidate_batch_size` | 20 | 正整数 |
| `candidate_concurrency` | 2 | 正整数，启动验证可分配资源数量 |
| `port_probe_timeout_seconds` | 3 | 正整数；仅 TCP 承载执行 |
| `tunnel_timeout_seconds` | 30 | 正整数 |
| `exit_check_timeout_seconds` | 10 | 正整数；所有候选地址尝试及跳转总预算 |
| `exit_check_max_attempts` | 3 | 正整数；每次独立随机，成功即停止 |
| `health_interval_seconds` | 60 | 正整数；必须大于 health_timeout_seconds，同一出口检查不重叠；环境变量为 VAP_HEALTH_INTERVAL_SECONDS |
| `health_timeout_seconds` | 5 | 正整数，小于健康检查间隔 |
| `candidate_retries` | 0 | 非负整数；节点握手/出口整体重试次数，与地址尝试不同 |
| `retry_initial_seconds` | 30 | 正整数 |
| `retry_max_seconds` | 300 | 不小于初始值 |
| `max_connections` | 50 | 正整数，包含认证和目标建连中的客户端 |
| `shutdown_timeout_seconds` | 15 | 正整数，内部清理预算为其 80% |
| `exit_check_urls` | 见下 | 至少一个 HTTP/HTTPS 地址，不能含凭据 |

默认检测列表：

```json
[
  "https://www.gstatic.com/generate_204",
  "https://cp.cloudflare.com/generate_204"
]
```

只请求响应头，不下载完整网页；最终 2xx 成功、空体成功、最多 5 次跳转。
HTTPS 必须校验证书，不能因失败自动关闭校验；跳转目标同样遵守工作进程的公网目标约束。
默认检测 DNS 复用工作进程的有界 IPv4 解析，固定隧道内公共解析器；不回落宿主 DNS。
时间字段应能安全转换为时长，溢出、非法地址、空列表、不可分配的并发配置启动即失败。
若健康检测尚未完成，跳过重叠调度，不累积任务。

## 凭据文件

独立文件内容形如：

```json
{"username":"lan-user","password":"替换为自己的密码"}
```

用户名密码均非空，UTF-8 编码长度各为 1—255 字节。文件仅属主可读，状态与错误不回显值。
配置示例不放真实密码；容器只读挂载秘密文件，原生由启动进程读取后再降权，
避免要求将密码放命令参数、镜像或普通配置输出中。

## 实例与校验顺序

苹果原生 `run` 还要求顶层 `macos` 对象：`dependency_manifest` 和 `runtime_parent` 是无跳转分量的绝对路径，`worker_uid` 与 `worker_gid` 指向明确的非管理员账户及其主组。相对路径在配置文件目录下解析后再校验。特权父进程只解析公开配置，不读取 `credentials_file`；凭据由身份核验后的低权限控制进程读取。持久 `data_dir` 必须由所选账户及主组拥有且为 0700，既有错误归属不自动修正，见[启动记录](../../../docs/validation/macos-run-entry.md)。

解析配置与凭据 → 检查实例锁和遗留资源归属 → 检查系统工具、能力、TUN 与网络空间操作 →
检查端口和数据目录 → 创建私有辅助进程及受控入口 → 获取/恢复节点并验证。

任一步骤失败回收已创建资源再退出；无可用节点属于运行状态而不是配置失败。
非回环地址无完整凭据禁止创建监听。不能因容器端口映射而自动绕过认证检查。

## 检测与重试语义

地址尝试总预算是 10 秒候选或 5 秒活动，默认最多 3 次，允许重复选中同一地址。
将剩余时间按剩余机会分配并设置每请求截止，外层总截止优先；到达总时限后不再请求。
一个节点整体尝试包含握手与一次出口检测；`candidate_retries` 控制整体重试，
不增加每轮不同节点数量。健康检测无连续多轮失败阈值，失败立即切换。

来源刷新失败和无节点恢复分别维护 30→60→120→240→300 秒退避，成功后重置。
相同且仍有效的来源成功刷新不能缩短无可用节点的既定退避；新增、重新出现、配置变化或从过期恢复有效的节点来源可以唤醒恢复。空来源不无条件清除节点恢复截止。2026-10-13 原源码短周期回归已复现相同刷新提前重试，修复后同回归通过，完整长测重跑中，见[记录](../../../docs/validation/long-tests-20261013.md)。
启动与故障恢复可提前开启候选轮次，但不并行叠加候选轮次；
有未过期成功候选时优先验证连接它，没有时遵循候选轮转，达到单轮配额后按退避继续。
故障恢复优先使用候选槽，必要时取消一个后台检测并完成清理后取得槽位。
正常节点只后台更新候选结果，不主动轮换。


## 苹果检测组件内部上限

T089 的独立低权限检测调用至多接受 32 个无凭据网页地址，每址 4096 字节、合计 32768 字节，最多 32 次请求；请求总预算为 1 毫秒至 120 秒，按毫秒向下取整。现有默认值满足上限。该组件拒绝超限，不静默裁剪；苹果公开配置及主服务仍待接入，届时须在启动预检给出一致诊断。进程控制与回收截止另列于[检测记录](../../../docs/validation/macos-exit-probe.md)，不能用它扩大实际请求预算或替代服务总停止预算。

## 苹果候选池内部配置

T096 协调入口复用共用配置，并要求数据与运行路径绝对、候选并发至多 32、节点整体重试至多 32、启动预算至多 120 秒，出口和健康参数继续遵守独立检测上限。检测结果有效期使用特权侧实际完成时间，不从协调方晚取走结果时重新计时；提升仍须特权侧单调时钟凭据复核。实际控制子进程及公开入口尚未接入，见[记录](../../../docs/validation/macos-source-coordinator.md)。

T093 内部健康设置独立提供间隔与出口检测参数，间隔须大于请求预算且可由单调时钟表示。每代际单调度所有者、首轮等待完整间隔、检测不重叠，错过截止的轮次丢弃且不突发补跑。检测结果通道只保存最近一条；结果为历史诊断，不能替代活动撤销令牌。当前尚未映射苹果公开配置或启用公共主服务，见[记录](../../../docs/validation/macos-active-health.md)。

T090 候选槽位接受 1 至 32，另保留一个活动槽位；接口配置串行，未知回收占槽并阻止新建并存接口。验证有效期须为单调时钟可表示的正时长，来源有效期须为正时长；启动预算、连接容量及检测设置继续遵守现有组件约束。内部库配置尚未映射公开服务配置，接入时须明确拒绝超限并保留独立健康调度配置，不能静默将既有平台候选并发裁剪为 32。

## 地区和时区语义（需-019、需-020）

- `countries`：可选字符串数组，默认 `[]`。最多 256 项，每项为两位英文字母，与来源 CountryShort 按大小写不敏感匹配。空数组接受全部；非空数组不匹配时等待，不回退。来源缓存保存完整原始有效节点，每次进入候选目录时应用当前筛选，历史检查不恢复可用性。配置变更须重启。
- `timezone`：可选 IANA 时区名称，默认 `Asia/Shanghai`；非法名称在启动前拒绝。结构化运行日志按地区规则显示偏移，支持夏令时；状态及缓存时间保持 UTC，调度仍使用单调时钟。服务器时区与 `TZ` 不覆盖显式配置。


两项字段保持配置模式版本 1；旧配置省略时仍可加载。显式 `null`、错误类型、带空白或非两字母地区值不视为省略；未知但格式合法的地区代码不会被改为全部地区。重复代码不扩大范围，仍计入 256 项上限。不要求运行中热更新。

候选总数为筛选后目录数量，来源快照和解析统计保持完整来源语义。无匹配时可说明地区限制；如果刷新同时失败，状态可优先呈现刷新错误，候选仍不越过筛选。显示时区并非缓存有效期或调度时钟来源。

旧版严格字段客户端与新版状态服务混用不作兼容承诺；新版客户端对旧服务缺少 `timezone` 的处理见命令行契约。

来源刷新后筛选视图为空，不主动断开此前按当前配置选出的健康活动出口，沿用需-001、需-006 的原规则；断开后不允许从范围外候选恢复。文中“无匹配时等待”指启动、重启或当前不存在健康活动出口的选择阶段。修改地区配置须重启，不提供热更新筛选或维持旧配置活动出口的承诺。

## 部署日志增量（003）

文件新增 `log_level`（error／warn／info／debug，默认 info）与 `log_summary_interval_seconds`（1—86400 整数，默认 60），对应容器变量 VAP_LOG_LEVEL、VAP_LOG_SUMMARY_INTERVAL_SECONDS。空环境采用默认，非法值在创建运行资源前拒绝；原生文件不接受环境覆盖。周期摘要只在 debug 输出，过滤不改变调度、状态、认证或故障阻断。具体规则见[日志契约](../../003-deploy-logging/contracts/logging.md)。
