# 外部隧道程序的本地实验补丁

2026-10-12，用户确认接受苹果首版预装带本项目补丁的专用隧道程序。依赖基线为固定 `OpenVPN 2.6.23` 加受控句柄借用补丁；`openvpn-2.6.23-utun-fd.patch` 当前仍是实验实现，生产加固、安装检查与完整分发材料尚未完成。

来源为官方 `OpenVPN 2.6.23` 源码：
<https://swupdate.openvpn.org/community/releases/openvpn-2.6.23.tar.gz>。
固定归档摘要为 `4041c709162bec1325abf5aa8cf27a255cc477c634b15ee310411c701fc40a96`。

上游版权为 `OpenVPN Inc` 等原贡献者，许可为其源码中 `COPYING`、`COPYRIGHT.GPL` 记载的第二版通用公共许可证及原有链接例外。补丁修改部分按与该文件相同的许可提供，保留原文件声明；本项目其他文件的许可不覆盖外部程序或补丁上下文。

构建入口为 `scripts/prepare-macos-openvpn-lease.sh`。每次从核对摘要的归档创建独立源码目录，保留完整上游声明，再应用补丁；配置、构建及本地安装日志都在验证目录。实验安装目录独立于标准依赖，不写系统目录、不启动服务。来源、补丁和二进制摘要保存到实验安装目录的 `provenance.json`。

补丁只识别由本地监督方生成的 `utun-fd:数字` 参数；拒绝标准描述符、非法数字、关闭的描述符及无关套接字。复制继承描述符后关闭子进程中的原副本，再设置禁止继续继承和非阻塞标志。监督方保留自己的描述符，子进程正常或异常关闭不会主动关闭监督方副本。不接受远端配置提供描述符参数。

本轮仅作本地实验，不公开分发补丁后的二进制。正式交付前须完善部署与完整来源材料交付方式并完成实际安全验收；不能用接受专用依赖这一决定替代验收。
