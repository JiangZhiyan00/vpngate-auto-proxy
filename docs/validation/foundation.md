# 共用基础验证

时间：2026-10-10，中国标准时间。

环境：苹果 ARM64 开发主机；本机容器引擎提供独立 Debian 12 ARM64 测试容器，Rust 1.90.0、OpenVPN 2.6.14。没有使用全特权、宿主网络、宿主命名空间或默认安全策略绕过。

已通过：

- 本机四项原始配置解析测试、十五项配置/模型/辅助协议契约测试，以及格式与静态检查。
- Linux 下全部普通测试和严格静态检查；三项特权集成测试以单线程显式执行，没有忽略。
- TCP/UDP 固定端点实际收发成功；普通业务用户、错误端口和错误承载无法经管理路径访问。
- 控制用户实际降至 10001，所有能力集合为零；受监督子进程终止、回收与重复停止成功。
- 缺少或不一致归属凭据时拒绝清理；正常清理后宿主路由、解析配置和全局转发值与原值一致。
- 受控来源生成两个基础节点及四十五个不同端点；夹具的真实 TCP/UDP 隧道、200/204、跳转、503、超时、有效 HTTPS、无信任证书拒绝和隧道内 DNS 通过独立验证。

复现入口：`tests/fixtures/setup.sh`、`tests/fixtures/validate.sh`；随后在专用测试环境设置 `VAP_NETWORK_TEST=1`，执行 `cargo test --locked --test integration -- --ignored --test-threads=1`。夹具使用自己的网络空间，结束后执行 `tests/fixtures/cleanup.sh`。

边界：以上证明共用基础和夹具，尚未证明完整代理、故障切换、容量、局域网实机、应用安全配置或三十分钟稳定性。Linux x86_64、Ubuntu 24.04 及发布容器矩阵尚未验证。
