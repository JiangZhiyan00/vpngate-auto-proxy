# 苹果低权限控制子进程接入

日期：2026-10-13，中国标准时间。T097 属于既有 T057 的细分，完整苹果后端仍未完成。

## 已实现路径

管理员监督入口要求明确的已有非零账户及其主组、受保护的当前程序安装、受控依赖及绝对数据与运行目录。全部预检后才创建本次私有身份材料并派生同一受保护程序的隐藏控制命令。程序清空继承环境，设置选定用户、主组与专属进程组，通过标准输入继承专用双向套接字；父方立即释放子端副本，配置和授权不通过公开监听器交付。

启动采用一个三秒总截止：父方发送配置，子方核对实际及有效用户和组、额外组清单、空环境、工作目录归属、私有配置不可读和所属验证文件可写。父方复核同一验证文件的实际节点与固定内容，明确确认后子方才进入来源协调和公共代理网关。启动就绪帧还必须属于本次授权、实例和仍存活的直属子进程号；这帧只表示控制进程交付，不表示已有可用出口。

特权侧仍独立持有候选池、检测成功凭据、隧道与代际任务。低权限子方复用既有来源协调及代理网关，代理认证文件也由子方在交付确认后读取；无已验证活动代际时拒绝业务，不创建直连替代。认证材料读取或网关绑定失败会结束子方并触发父侧池回收。

控制通道结束、直属进程退出或停止请求会取消池监督，并等待所属任务回收。握手失败直接回收本次直属进程；已运行子方先获得配置的正常退出时间，超时只对持有的本次子进程句柄强制回收。收到明确回收凭据后才清理身份材料。外层等待被丢弃时，取消信号交给同一后台所有者，后台继续回收；不能据此推断整个运行时被强制终止后也已清理。

## 剩余边界

此组件尚未接入公开启动命令、本地实例状态与停止监听、实例锁、持久归属清单及安全重启。现有公共启动行为未据此启用苹果后端。管理员实际跨账户运行、真实来源与公网出口、双承载、端到端持续连接、完整监督故障及宿主基线仍须执行或完成；上述普通权限回归不能替代它们，T057、T058 继续未完成。
