# 苹果特权代际启动与归属目录

日期：2026-10-12，中国标准时间。T087 细分自 T057，完成库内的特权代际调用、目录事务、直属子进程回收凭据及受控描述符创建与派生串行化。管理员真实执行与正式主服务接入尚未完成。

入口为 `src/platform/bootstrap.rs` 的 `run`。顺序是：真实与有效管理员身份、明确已有的非零用户及主组、容量与截止、重新生成配置的公网白名单、自身受保护安装记录、固定依赖记录；全部通过后才准备代际目录、创建控制接口、启动直属隧道，再交给地址配置、作用域默认路由、低权限业务启动和持续联合监督。普通权限调用在读取不存在的部署材料之前拒绝。入口不创建账户、不放宽公网配置限制，也不将私有工作进程就绪当作出口验证或活动提升。

父目录须由管理员预先提供，真实祖先受保护，权限为 0711 或 0755。可选短路径例如 `/private/var/vap`，实际路径仍须全部核验；不要使用经过符号链接的别名。2026-10-13 本机只读核对发现 `/private/var/run` 为 0775，因此此前位于其下的示例不满足保护要求，不能使用该路径或改动系统目录权限来绕过检查。每次创建独立 `g-随机身份` 目录：代际根 0711、管理员隧道子目录 `t` 为 0700、指定业务用户及主组的 `w` 为 0750，隧道配置与归属记录为管理员私有 0600。任何预存同名节点均拒绝接管。管理与业务套接字使用紧凑随机文件名，准备前检查完整路径长度，超限时不创建材料。首次测试发现默认临时目录过长，改为短路径真实夹具后通过；不是放宽系统限制。

归属事务记录设备号、节点号、用户、组与类型。回收先复核全部节点，再按登记顺序逐项非递归删除；替代节点、未知业务目录内容或删除失败均拒绝继续，并尽量保留清单与路径。准备失败仅回滚本次创建且身份相符的节点。对象丢弃或异步调用被取消时不自动删除可能仍被消费者使用的材料。

直属隧道及业务子进程各有独立的进程内回收凭据。尚未派生时标为无消费者，成功派生后立即撤销该状态，只有从本次直属子进程对象明确观察到退出并回收后才能恢复。协议错误、启动失败与强制回收可以同时发生：错误仍返回，但确认两侧回收后允许清理所属路由及目录；未确认则保留。凭据不使用裸进程号识别，也不持久化为重启依据。

苹果系统上部分套接字创建或接受连接需要后续设置执行时关闭标志。控制接口、地址及路由控制通道、管理监听和接受、控制套接字对与受控子进程派生共用同步临界区；接受连接只保护单次非阻塞轮询，不跨异步等待持锁。相关管理员路径核验所用的系统子进程也进入同一临界区。未来增加特权描述符创建或派生入口时必须审查此边界，不能据本轮普通权限并发回归宣称整机继承隔离已验收。

业务派生明确设置用户和主组。标准库规定设置用户且未显式指定附属组时会清空继承的附属组，见[官方接口说明](https://doc.rust-lang.org/std/os/unix/process/trait.CommandExt.html#tymethod.uid)。实际管理员降权、文件归属变更及业务身份仍需原生核验；普通事务测试注入归属变更，不能替代该证据。

十五项新增回归覆盖真实目录事务、拒绝与失败回滚、归属替代及未知内容、停止与权限前置、账户主组和启动限制、材料保留与错误合并、真实直属子进程回收、协议失败后仍确认回收，以及并发临界区和异步接受连接的继承标志。完整默认测试通过 164 项单元和 63 项契约，35 项环境或显式依赖测试保持忽略；格式、严格静态检查及锁定构建通过。没有增加依赖或不安全代码。机器记录见[工具证据](macos-bootstrap-tools.json)，完整本地日志位于 `validation-output/macos-bootstrap-20261012/all-tests.log`。

仍有明确缺口：主服务的来源、候选验证、活动提升及命令管理尚未接入；静态候选的完整管理员原生调用、双承载、公网出口与解析、防直连、完整监督崩溃、正常网络变化、宿主基线与安全重启尚未验收。外层还必须释放就绪材料及并存材料复制件，避免继续固定已退休接口。业务被强制退出后可能遗留的私有监听须有精确节点归属才能自动清理，本轮对未知内容保留并报错。

`ownership.json` 只记录本轮文件系统节点；`creator_pid` 仅供诊断，`consumers_may_exist=true` 明确禁止将清单当作无消费者证明。它不是含启动身份、真实网络资源及全部消费者的恢复清单，不能据此自动杀进程、递归删除或宣称安全重启完成。T057、T058 及另外七项主验收仍未完成；三十分钟测试继续暂缓。需用户操作的项目见[待执行事项](pending-user-actions.md)。
