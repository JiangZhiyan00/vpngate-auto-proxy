# 苹果控制通道异步候选检测

日期：2026-10-13，中国标准时间。T095 是已有 T057 的集成细分；本轮解除串行控制通道对候选检测并发的限制，公共主服务仍未完成。

## 行为与归属

控制协议增加 `BeginVerify` 和 `VerifyResult`：前者登记独立检测所有者后立即返回，后者在任务未完成时返回进行中，完成后取走一次结果。两个已就绪候选可各有一个独立检测任务；控制连接继续串行收发短请求，检测执行期间仍能处理其他请求。原 `Verify` 保留同步等待语义，后续候选轮次应使用异步入口实现并发。

每个检测任务在派生时已拥有所属代际的检测会话及全程回收登记。任务持有固定池、工作、代际、配置摘要与独立取消令牌；正式检测仍在既有低权限子进程执行，不复制真实接口控制句柄。只有正式成功、仍存活且未取消的检测才能生成服务端提升凭据；提升时仍再次核对当前池、来源、代际和时效。

同一工作代际已有未取走的检测时，重复异步启动或同步检测均拒绝，不叠加任务。结果只能取走一次；成功凭据继续留在特权侧。重新开始检测先移除旧凭据，退休、停止或通道故障移除任务所有者并发出取消。实际任务不会被中止，候选池仍等待其会话及直属检测回收；取消任务结果等待后可以继续等待同一任务。丢弃未取走的检测会立即撤销所属代际，任务异常也撤销；取走成功结果后丢弃空所有者不撤销健康代际。退休后迟到结果不能重新提升已删除代际。

控制通道仍不提供异步状态推送，实际控制子进程启动与身份核验、来源轮次、公共网关及本地活动引用撤销接入仍待完成。不能把本组件测试写成公共主服务或管理员原生验收通过。

## 普通权限证据
