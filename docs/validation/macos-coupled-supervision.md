# 苹果隧道与业务进程联合监督

日期：2026-10-12，中国标准时间。T076 按联合监督组件及普通权限真实子进程验证范围完成；属于已有 T057 的实现细分，不表示正式苹果服务或完整故障验收完成。

`src/platform/session.rs` 将 T074 的直属业务工作进程与 T075 的隧道管理会话组合。调用方交入自己直接启动并仍持有的隧道子进程、私有管理连接、预期隧道用户及已授权远端地址。业务工作进程已完成私有就绪握手，联合监督还要通过内核对端身份检查、管理连接成功状态及远端地址一致性检查，才发送连接材料。材料仍须交给正式验证流程核对接口地址、公网路由、业务与解析归属，不能直接发布活动出口。

联合监督同时等待业务子进程、隧道子进程、管理会话和停止信号。业务意外退出、隧道退出、管理断开、重连、异常管理状态、启动超时、身份不符或远端地址变化，均结束本代际；不会让另一个子进程独立继续存活。已经收到停止信号时，不再发布连接材料。连接材料接收方提前退出也触发清理。

每条正常返回路径先结束管理会话、关闭管理端，再通知业务退休并等待其确认与实际退出；业务退休失败仍继续回收隧道。管理断开后隧道有两秒正常退出窗口，超时则强制终止并再限两秒回收。业务沿用四秒退休及两秒强制回收预算，整个停止路径预算合计最多十秒，不计极端系统调度延迟。保留监督、业务退休和隧道回收的各阶段错误，不能因为其中一步失败就跳过后续回收，也不能将强制终止冒充正常退休。

组件独占两类直属子进程。正在运行的联合监督任务被取消或组件被丢弃时，立即关闭业务控制端及管理端，并尝试终止隧道；业务子进程沿用丢弃时终止策略。异步等待无法在析构中完成，因此只有正常等待联合监督返回才能据其结果确认回收成功。取消回归中，仍运行的异步运行时最终回收两类进程；这不代表整个监督服务被强制终止后的持久恢复已实现。

七项普通权限真实子进程回归通过：

- 正常停止：业务退休握手、描述符释放及两类子进程实际回收均完成才返回成功。
- 管理断开、重连及隧道异常退出：业务退休并回收；故意不响应管理关闭的隧道也被强制回收。
- 启动拒绝：错误管理用户、错误远端和启动静默超时均不发布连接材料，已启动的业务子进程仍被回收。
- 业务强制退出：关闭隧道管理会话并回收隧道。
- 两类子进程均无响应：先执行各自的限时正常路径，再强制终止及等待；错误保留。
- 监督任务取消：控制句柄对端结束，两类进程由仍存活的运行时回收。
- 启动前已停止：不发布连接材料，两类子进程和持有句柄均释放。

测试通过真实私有套接字、真实子进程、描述符对端及进程状态核对行为。测试子进程模拟管理协议和业务退休握手，不创建系统接口，也不执行真实业务网络请求。正常停止用例在联合监督未实现时实际失败，完成组合后通过。完整检查通过：52 项单元、63 项普通契约；格式、严格静态检查及锁定依赖构建通过。一个需显式外部依赖的管理协议回归、三项环境专用契约和二十九项特权集成按默认条件跳过；前一轮外部程序管理兼容性证据保留，不计为本轮新增原生隧道证据。
