## 已通过

- 三项恢复调度契约：当前配置且未过期的出口成功者优先，最近成功时间和稳定标识排序；清除旧队列、等待运行任务清理；来源与节点各自退避，默认三十至三百秒，饱和上限及成功重置。
- 五项真实隧道集成：结构故障在五秒内识别，不等待配置为六十秒的 HTTP 周期；撤销活动后旧长连接关闭；同一监听入口通过另一个重新验证的节点恢复。
- HTTP 检测全部失败后阻断请求，失败备用不提升；恢复时保持旧节点失败，只放开另一承载，确认启用另一节点。
- 活动健康检测总时限一秒、三次机会，单轮失败立即阻断，不累计多轮阈值；健康检测与后台候选并存时旧长连接不关闭、不主动轮换。
- 无可用节点短时等待十五秒，完成七轮实际检测；进程保持存活，请求被阻断，各轮等待符合一至二秒测试退避。该缩短配置不替代默认退避的三十分钟稳定性证据。
- 三组管理网卡抓包分别观测到 180、260、601 条封装包，业务和域名解析目标明文包零条，包含等待期间以节点端点地址为业务目标的尝试；停止后路由、防火墙、系统解析及转发值与基线一致。

测试先复现恢复优先级、资源等待及退避断言失败，再实现；真实集成还发现了较低优先级节点并发抢先提升的问题，修正为恢复阶段按优先级逐个验证后通过。正常后台检测保留配置并发上限。

## 运行行为及边界

每秒检查活动进程、接口和分流路由，HTTP 检测默认每十秒一次、总时限五秒，彼此独立且同类不重叠。故障先清空活动引用并取消旧连接，再停止旧资源及后台任务，等待候选槽清理后恢复。所有待启用隧道必须完成实际出口验证，成功后原地提升。

运行汇总包含最近活动检测的节点、工作进程、时间、次数、耗时、响应状态和失败分类，以及最近切换原因。事件使用带中国标准时区的时间，预算使用单调时钟；不记录业务目标、正文或秘密配置。
