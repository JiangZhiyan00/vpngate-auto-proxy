# 独立监督通道退出实验

日期：2026-10-12。对应 T070，工具、普通权限回归及两种承载的管理员原生实验均通过，T070 按限定范围完成。T057、T058 保持未完成，三十分钟测试继续暂缓。

## 实验机制

独立进程唯一持有外部隧道程序的管理会话和业务工作进程的控制端。管理套接字位于本次私有运行目录，权限为 0600；管理参数由本地生成，不接受远端配置指定路径。工作控制端通过专属套接字交接，要求恰好一个描述符；重复、截断或错误类型使独立进程退出。观察方收到交接确认后关闭自己的业务控制端及隧道控制句柄。

采用固定外部程序的 `--management-client --management-hold`：连接成功后由通道所有者放行。固定版本的[管理选项说明](https://raw.githubusercontent.com/OpenVPN/openvpn/v2.6.23/doc/man-sections/management-options.rst)及[实现](https://raw.githubusercontent.com/OpenVPN/openvpn/v2.6.23/src/openvpn/manage.c)规定管理客户端断开后触发终止。此实验不依赖只触发重连的管理信号选项。

先核对真实业务代际及候选业务、解析，再只强制终止通道所有者。观察方在六秒总截止内只等待两个消费者自行退出，不向它们发送停止信号。要求业务工作进程正常退休，外部程序正常退出且日志明确包含 `SIGTERM[soft,management-exit]`；最后持有者退出后接口消失，存活候选业务及解析仍通过，活动连接及宿主基线回收满足既有门槛。失败后的清理仍负责回收本次资源，不能把清理动作算作故障阶段通过。

观察和回收进程始终存活，私有路径也不等同于正式进程认证。此项仅验证独立通道所有者故障传播，不证明完整生产监督崩溃、全部网络路径零直连或安全重启。

## 已完成验证

新增十七项测试通过，完整苹果脚本回归共一百三十五项通过；示例构建及四个相关脚本语法检查通过。真实进程测试包含控制端唯一交接、重复及截断拒绝回收、通道关闭后的业务代际退休和已登记连接释放。阶段记录使用有界二进制分帧，并测试多条记录同批到达，避免文本预读造成错误超时。

固定外部程序还通过普通权限的等待阶段实验：使用空设备且不放行管理等待，通道所有者强制退出后外部程序自行退出，日志核对管理断开原因。此项未创建宿主隧道，不属于真实加密隧道原生证据。完整工具证据及源码摘要见[工具记录](macos-supervision-tools.json)。
