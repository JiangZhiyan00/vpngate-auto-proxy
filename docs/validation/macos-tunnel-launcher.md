# 苹果隧道串行启动入口

日期：2026-10-12，中国标准时间。T077 按独立启动入口与普通权限回归范围完成，属于 T057 的实现细分。管理员安装、特权父进程接入与完整原生后端仍未完成。

`src/platform/launcher.rs` 提供独立启动桥接。`src/main.rs` 在创建异步运行时和其他线程之前处理隐藏入口；成功时以同一进程号替换为固定隧道程序，任何失败直接结束本次启动进程。普通公开命令继续进入原有异步应用。

启动要求真实与有效用户均为管理员。依赖记录、程序、私有配置、管理套接字及其所有祖先目录须由管理员所有，不得允许组或其他用户写入，不得使用符号链接或扩展访问控制表。配置和管理套接字要求权限 0600，管理目录要求 0700。配置经过既有重建白名单验证，远端必须与本次授权端点一致。

依赖记录拒绝未知字段，包含以下六项：

| 字段 | 要求 |
| --- | --- |
| `format_version` | 固定为 1 |
| `version` | 固定为 2.6.23 |
| `source_sha256` | 固定源码摘要 `4041c709162bec1325abf5aa8cf27a255cc477c634b15ee310411c701fc40a96` |
| `patch_sha256` | 固定借用补丁摘要 `cdf11425bb5806f87eb6fb5ee289adba86e7de3c08bbe550a777785d05b986fa` |
| `binary_path` | 管理员保护的绝对程序路径 |
| `binary_sha256` | 安装后实际程序的非零、小写十六进制摘要 |

旧实验来源记录不能直接充当上述安装记录。程序摘要核验后，直接读取 ARM64 单架构程序及非系统动态库的加载记录，递归检查库的管理员所有权及路径保护；不执行开发工具目录中的解析程序。拒绝相对库路径、运行时搜索路径、加载环境注入、未知加载命令和不支持的二进制格式。系统动态库路径交由系统维护；当前不支持通用多架构程序。

私有标准输入通道接收本次授权标识、索引和唯一控制句柄，并核对真实接口身份。完成全部核验后，只在最后一个串行步骤允许本次控制句柄跨执行替换继承。清空继承环境，固定系统搜索路径与动态库回退目录，禁用外部加密配置，并将加密模块目录限制到管理员私有管理目录。执行替换失败时恢复句柄标志并关闭句柄，不重试。

固定启动参数包含 `--ifconfig-noexec`：远端地址材料不能直接触发管理员网卡配置。特权辅助方仍须校验地址并配置本次所属接口和路由。因此当前入口尚不能独立提供正式业务出口。输出描述符也须由后续可信父进程安排。

## 验证结果

七项默认单元回归通过，覆盖权限清单、安装记录、加载记录与截断拒绝、真实受保护系统文件摘要、替换失败释放句柄，以及真实子进程同进程号替换、单一套接字继承和环境清理。实际固定实验程序的加载记录另行显式读取通过；该检查不执行隧道，也不代表管理员安装通过。

执行替换失败可能改变调用进程的信号状态；相应回归已隔离到独立子进程，产品入口失败后直接退出。完整并行检查通过：59 项单元、63 项普通契约；默认未执行的两项显式依赖单元、三项环境契约和二十九项特权集成不计通过。格式、严格静态检查及锁定构建通过。新增入口的两项普通权限脚本回归及既有工作进程两项回归通过。

新容器镜像 `vpngate-auto-proxy:launcher-check` 发布模式构建通过，镜像摘要为 `sha256:62d4a8bb933ad51c911987d1fd977879353335a671979d657564487f881c5820`。在无网络、移除全部能力、只读文件系统下，帮助、版本和无效配置退出三项入口检查通过；未执行容器长试或特权网络矩阵。依赖只增加已有固定版本库的功能开关，没有新增依赖包或版本。

复现普通权限检查：

```sh
cargo test --locked --quiet
cargo clippy --locked --all-targets -- -D warnings
cargo fmt --check
cargo build --locked
python3 -m unittest scripts/test_macos_tunnel_launcher.py
```
