# 苹果直属隧道父进程

日期：2026-10-12，中国标准时间。T078 按父进程启动组件、联合监督接入与普通权限真实子进程回归范围完成，属于已有 T057 的实现细分。未执行管理员正向启动或真实隧道，完整苹果后端仍未完成。

`src/platform/tunnel.rs` 的公开启动入口只接受已核验的真实控制句柄、授权公网端点及受保护材料路径。真实和有效用户须均为管理员；复用串行桥接的路径保护核验，要求管理员所有的 0700 管理目录、本项目程序、依赖安装记录与 0600 私有配置。公开接口没有可执行程序覆盖参数。

父进程为每次启动创建独立管理套接字，设为 0600，再派生同一项目程序的隐藏串行入口。子进程使用独立进程组、清理后的环境与空输出端，不继承任意参数或父进程日志描述符。真实句柄身份核验后即设置执行时关闭标志；父方复制时再次保护原件，再取得执行时关闭的复制件，通过专属标准输入通道交接授权标识、索引和唯一句柄；发送后关闭本次复制件及交接端，保留调用方原有真实句柄所有权。桥接继续执行 T077 的程序摘要、加载库、配置和接口身份核验，再以同进程号替换为固定隧道程序。

启动总截止覆盖父方派生、句柄交接及管理连接等待，最多 120 秒，交接阶段最多三秒。取消、子进程提前退出、超时或管理身份不符均拒绝启动。接收连接后通过内核凭据核对直属子进程号及预期用户；连接前后都检查实际进程状态。此阶段只确认管理连接归属，不释放隧道等待、不发布连接材料或业务出口。

启动失败先关闭管理端，最多两秒等待退出；无响应时通过仍持有的直属子进程对象强制退出并最多两秒回收。保留启动与回收错误，并继续清理端点。正常停止也采用同一有界回收逻辑；强制回收不能冒充正常退出。端点清理核对文件类型、设备号、文件节点号及用户，只删除本次节点；路径被其他套接字替换或已有普通文件时拒绝删除。

`CoupledMacGeneration::from_tunnel` 接收已启动的隧道和业务工作进程，核对两者接口索引一致，保留隧道原有授权远端及预期用户，移交直属子进程、已认证管理连接和端点归属。接口不匹配、启动截止无效或隧道已经退出时，等待两侧清理后返回错误；任一步失败仍尝试另一侧，保留各阶段错误。正常联合监督完成双进程回收后核对并删除管理端点。

启动未来或持有对象被取消、丢弃时，立即关闭管理端、尝试终止直属子进程，并通过端点守卫清理本次节点。析构不能异步等待，只有显式等待回收成功才能确认回收完成；取消回归中最终进程回收依赖仍存活的异步运行时。本组件不证明整个生产监督服务崩溃后的持久恢复。

## 验证

正常启动与退休回归在尚无实现时实际失败，完成后通过。八项新增父进程回归通过：

- 启动真实子进程、核对固定交接材料、环境和继承边界，正常退出后描述符对端关闭、子进程已回收、管理端点删除；退休后不能再次移交给联合监督。
- 提前退出与启动静默超时均完成回收。
- 错误管理用户及同用户的错误进程均拒绝。
- 零索引、无效截止、非公网端点及启动前取消均不派生子进程。
- 启动中取消等待回收完成后返回。
- 启动任务取消后，在持续运行的运行时内最终回收进程和句柄。
- 不响应管理关闭的隧道被强制回收，返回超时错误。
- 被替换和预先存在的端点均保留。

另有一项独立进程回归验证保留原件与启动复制件均不隐式继承，实际派生的检查子进程中没有额外套接字。临时移除原件保护时该回归实际失败，恢复后通过；制造可继承句柄的过程隔离在专用测试进程中。

一项新增组合回归覆盖三个场景：父进程启动的隧道正常移交联合监督并等待两个消费者回收；错误接口拒绝接入并回收两侧；无效截止拒绝接入并回收两侧。全部使用真实私有套接字、描述符及直属子进程，但隧道程序模拟协议，未创建系统接口、配置路由或访问公网。测试用可执行覆盖入口仅在测试编译中存在。

完整检查通过：69 项单元、63 项普通契约；两项需显式依赖的单元、三项环境契约和二十九项特权集成默认未执行，不计通过。格式、严格静态检查和锁定构建通过；串行启动与既有业务工作进程的四项脚本回归通过。最终检查无本轮测试子进程残留。本轮没有新增依赖或修改 Linux 运行路径，未重跑容器网络验收。

排查中将测试进程启动预算从半秒改为三秒，避免把解释器启动延迟当作预期提前退出。一次完整并行回归还出现既有解析测试重新绑定临时端口失败；后续完整回归通过，原断言保留。该次端口占用原因尚未确定，不据复跑通过宣称已修复继承竞争；管理员原生组合验收仍须核查业务资源和子进程继承边界。
