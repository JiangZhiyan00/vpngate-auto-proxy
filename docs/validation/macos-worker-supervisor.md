# 苹果直属业务子进程启动与回收

日期：2026-10-12。T074 按直属业务子进程管理及普通权限验证范围完成；尚未接入正式苹果服务或取得管理员原生验收。

`ManagedMacWorker::start` 只启动当前程序本身的隐藏工作命令，不从外部协议接收可执行文件或任意参数。调用方必须交入已经核验的 `UtunCustody`。监督方生成授权标识和私有工作路径，创建专属套接字对，将子端作为标准输入传入，关闭自己持有的子端原件，再从父端发送控制句柄。原句柄先复制为执行时关闭的句柄并关闭原件，避免绕过私有交接隐式继承；句柄仅在首次发送附属数据，部分写入时后续只发送剩余启动帧。

用户、组、接口索引和连接上限必须有效，用户及组不得为零。私有运行目录必须为目标用户所有、组与目标组一致、权限 `0750` 的普通目录；拒绝目录符号链接以及带执行时改变身份位的程序。子进程清空继承环境，设置固定系统工具路径和语言，使用独立进程组并配置丢弃时终止。启动通过标准库指定目标用户及组；标准库说明指定用户会安排清空补充组，见[正式文档](https://doc.rust-lang.org/std/os/unix/process/trait.CommandExt.html#tymethod.uid)。本轮只验证普通用户启动同身份子进程，不能替代从管理员降权后核查实际身份、补充组与权限的原生验收。

监督方验证 T073 就绪帧，并确认直属子进程尚未退出后才返回工作引用。就绪接收限三秒，句柄发送另限三秒；退休确认与正常退出共用四秒总预算。错误确认、断开或超时会关闭控制端，随后通过直接持有的子进程句柄强制退出并限两秒回收，避免通过外部缓存的数字进程号管理进程。只有正确退休确认与正常退出都满足才返回退休成功。退休等待被取消后仍可重试强制回收；等待取消本身不算退休成功。

六项普通权限真实子进程测试覆盖：正常启动、非零身份及独立进程组、恰好一个私有交接句柄、交接前不隐式继承套接字、正常退休和描述符释放；错误就绪及启动总截止后的强制回收；停止不响应、退休后不退出、错误退休代际后的强制回收；退休等待取消后的重试回收；零用户拒绝；不安全目录及改变身份的程序在启动前拒绝。测试核对进程不再存在，也核对描述符对端结束；测试子进程仅模拟协议，不是真实隧道。已运行构建、完整 Rust 测试、格式、严格静态检查及两个真实单文件失败入口回归，均通过。三项环境专用契约和二十九项 Linux 特权集成测试按既有条件跳过。

当前没有正式特权辅助方创建并交入真实控制句柄、创建低权限运行目录或记录苹果进程启动身份；`service::run` 仍只启用 Linux。强制退出可能留下尚无持久归属清单的工作套接字，本模块不推测并删除该路径；正式辅助方还须实现可核对的路径归属和异常遗留恢复。完整隧道管理会话、业务路由、活动切换、管理员降权、生产监督崩溃和安全重启仍待实现及原生验收。T057、T058 保持未完成，三十分钟测试继续暂缓。
