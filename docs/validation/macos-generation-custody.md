# 业务代际句柄回收原型

日期：2026-10-12。对应 T067；本次验证进程内资源生命周期，不代替原生隧道或完整苹果后端验收。

用户已确认首版覆盖本项目进程崩溃、隧道断开及正常网络变化，排除外部管理员主动破坏接口。业务及解析不回退直连、候选隔离和安全重启要求仍有效。

## 实现与约束

`src/platform/generation.rs` 新增 `WorkerGeneration::with_custody`，接收独占所有权描述符并随代际共享状态持有。登记操作持有读锁；正常退休永久撤销代际，等待全部登记操作释放后取得写锁，关闭句柄并返回退休确认。旧引用继续存在不阻止正常退休关闭句柄，旧引用不能重新接纳操作。

退休等待被取消时不提前关闭句柄；调用方可重新等待退休。监督对象丢弃时撤销代际，句柄由存活业务引用及登记操作继续保持，直到正常退休或最后一个共享引用释放。

描述符来源、授权和接口身份须由平台后端验证。登记操作必须拥有全部网络资源，不能返回可继续联网的句柄、把资源放入外部容器或派生未登记任务；此约束仍须由正式工作进程封装保证。退休确认不等于子进程退出。实现没有新增依赖或不安全代码，尚未接入正式业务及解析路径。

## 验证

先用提前丢弃传入描述符的临时实现验证测试能发现错误：首次句柄保持断言观察到连接关闭而失败。随后实现正确持有与回收，十一项代际测试全部通过。新增四项使用真实套接字：

1. 旧引用仍存在时，正常退休关闭句柄并拒绝旧请求。
2. 取消登记的真实回环流式连接时，连接资源析构期间句柄仍存在；退休确认后连接及句柄均已关闭。
3. 取消尚未完成的退休等待后保留句柄，显式重试退休才关闭。
4. 监督对象丢弃后，已撤销的存活引用保持句柄，最后一个引用释放后关闭。

句柄关闭通过本地域套接字对端读取到连接结束确认；保持通过非阻塞读取返回暂不可读确认。
