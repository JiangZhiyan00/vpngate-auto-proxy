# 苹果系统内部工作进程接入记录

日期：2026-10-12。T072 的代码接入与普通权限回归已完成，按限定范围勾选；正式监督方及公网路由原生验收仍属 T057 的必要工作。

单文件内部 `mac-worker` 命令从专属私有启动通道接收一个控制句柄，核对授权标识、数字接口索引和真实 `utun` 身份后，才建立私有 SOCKS 工作套接字。其请求沿用现有无认证内层 SOCKS 握手和目标限制：外层客户端认证仍由网关负责，内层套接字须位于仅受信进程可访问的私有目录。域名查询调用已登记的代际网络入口，不使用宿主系统解析；目标连接成功后才发送 SOCKS 成功应答，之后在同一登记操作内双向转发。控制通道结束时停止接纳、撤销代际、终止请求任务并等待退休；入口拒绝非公网地址和端口零。

普通权限真实套接字测试覆盖：完整私有 SOCKS 域名请求经过固定接口解析、目标连接和双向转发，撤销后关闭目标连接并移除工作套接字；私有 SOCKS 通道拒绝直接指定回环目标且没有产生目标连接；固定接口 DNS 查询与目标筛选；目标连接成功后才发布成功帧，失败时只发布失败帧；真实子进程收到普通套接字伪造的控制句柄后，以失败状态退出且不建立工作套接字。端到端回环用例仅通过测试专用的代际策略和解析服务器参数接入，不改变生产入口固定公网目标及解析服务器。已运行 `cargo build --locked`、`cargo test --locked`、`cargo clippy --locked --all-targets -- -D warnings`、`cargo fmt --check` 和 `python3 -m unittest scripts/test_macos_verified_worker.py`，均通过。现有二十九项专用 Linux 特权集成测试仍按既定条件跳过。

当前 `service::run` 仍只允许 Linux；苹果系统尚无正式监督方来启动该内部工作进程、转交真实隧道句柄、建立候选与活动业务路由并控制切换。正向端到端回归使用回环测试策略，未证明完整 SOCKS 请求在真实公网隧道上的出口归属、零直连、生产故障恢复或安全重启。T072 按内部工作进程与普通权限验证范围完成；T057、T058 保持未完成，三十分钟测试继续暂缓。
