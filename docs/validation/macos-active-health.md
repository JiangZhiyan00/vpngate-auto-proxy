# 苹果活动出口独立健康调度

日期：2026-10-13，中国标准时间。T093 是已有 T057 的服务集成细分；本轮完成库组件及候选池接入，公共主服务和管理员原生验收尚未完成。

## 行为

当前活动代际可通过候选池的 `start_health` 启动一个独立健康调度所有者。候选代际、外部工作标识、重复启动及无效设置均拒绝；无效设置不撤销已有健康活动出口。健康设置单独提供检测网址、请求次数、请求预算及检查间隔，不沿用候选检测预算。间隔须大于检测预算且可由单调时钟表示，其余约束复用正式出口检测设置。

首轮在完整间隔后执行；单个代际的健康轮次串行，不产生重叠任务。正常检查沿调度截止继续，检查及回收拖过下一截止时丢弃错过轮次，从完成后再等待一个间隔，不突发补跑。候选建立、就绪等待及候选检测不阻塞独立健康任务。

实际请求复用正式低权限检测子进程及活动代际私有工作端。整轮检查失败或检测监督错误立即撤销所属代际，在发布结果前阻断旧引用；不增加连续失败阈值、不重试整个健康轮次，也不自动重新发布活动引用。现有单轮检测器内部请求次数规则保持不变。健康调度异常退出或被丢弃也撤销代际；切换和恢复仍由后续服务编排接收结果并退休、验证候选后执行。

结果通道只保存最新一条，不积压历史事件；结果包含工作标识、代际标识、轮次序号、起止时间及检测报告或错误。最后成功结果只作历史诊断，不能证明撤销后的代际可继续使用；调用方仍须遵守活动引用撤销令牌。旧代际在撤销后返回的成功结果不会新发布。

## 检测会话与回收

检测会话复制私有工作端路径、代际身份及撤销通知，不复制真实控制句柄。会话创建时即占用所属检测登记，整个会话存活期间保持登记；每次实际检测另有直属子进程回收凭据。停止先撤销代际，再等待会话释放及所有直属检测回收，避免在登记暂时为零时误报清理完成后又派生检测。已停止会话拒绝后续检查。

候选池同时等待健康所有者与代际监督回收，不中止运行中的检查未来。取消停止等待后保留同一任务，可以继续等待；丢弃所有者只发出取消并让原回收任务持续运行，外层运行时必须保持存活。逻辑检测失败与清理确认独立：已确认回收可释放槽位并保留失败诊断，未确认回收仍保留槽位。既有直属进程回收凭据、作用域路由和目录核验保持生效。

## 验证与边界

新增十一项普通权限回归：八项健康调度测试覆盖首次截止、结果身份、失败撤销、监督错误、不重叠及错过轮次丢弃、取消等待与继续退休、丢弃后持续回收、任务异常、迟到成功拒绝及无效设置；一项生命周期测试覆盖会话占位、停止拒绝后续检查及释放后确认回收；两项候选池测试覆盖仅活动准入、重复所有者拒绝、无效设置不影响活动出口，以及候选建立尚未完成时活动健康检测仍运行。

候选建立期间的检测使用正式普通用户权限拒绝路径，确实撤销活动引用并回收两代际；成功健康结果及时间推进使用注入测试检查器，不代替真实管理员降权或网页请求证据。已有正式出口检测的真实直属子进程回归继续通过。

完整结果：221 项单元、67 项契约通过，35 项目标或特权用例保持忽略；格式、严格静态检查及锁定构建通过。未增加依赖版本或本项目不安全代码。日志位于 `validation-output/macos-active-health-20261013/`，见[机器记录](macos-active-health-tools.json)。
