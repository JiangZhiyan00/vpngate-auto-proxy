## 安装行为

`src/platform/dependency.rs` 提供普通权限只读核验和显式管理员安装，两者共用材料解析与摘要检查。安装入口在读取材料前要求真实和有效用户均为管理员。输入文件使用不跟随符号链接的非阻塞打开，只接受无硬链接的普通文件；检查单文件与总大小、所有摘要、非空声明文本及静态归档格式。管理员安装不执行候选程序、不解压归档、不运行编译器或其他外部工具处理候选；二进制加载记录直接复用项目解析器，拒绝非系统动态库。

全部材料读入并完成核验后，才准备管理员所有的 0700 项目和依赖目录。安装先写独立私有暂存目录，程序权限 0700，材料及记录 0600；写入并同步完整材料和最终路径的六字段启动记录，再通过系统不覆盖重命名原子提交。目录名包含完整程序摘要。既有文件、目录或符号链接均不覆盖，并发安装同一版本只能有一个成功。失败时只清理仍符合本次设备号、文件节点号和用户归属的暂存目录；清理失败与原始错误一并返回。原子提交后的父目录同步失败会报告错误，已提交材料保留，服务仍不激活。

安装根目录固定为 `/Library/Application Support/vpngate-auto-proxy/dependencies`，不接受外部目的路径。成功返回 `dependency_manifest` 路径和 `service_activated=false`，不修改全局配置、替换系统标准程序、启动服务或配置网络。主程序本身的管理员保护安装、低权限身份和正式后端配置仍待接入。

启动桥接继续清空继承环境，并固定加密配置、模块和引擎目录；相关变量的行为依据[加密库官方说明](https://docs.openssl.org/3.6/man7/openssl-env/)。静态候选在禁用外部配置的普通权限环境下实际列出默认加密算法，确认所需算法可用。

## 复现与后续管理员步骤

在仓库目录普通权限构建与核验：

```sh
cargo build --locked
python3 scripts/prepare-macos-dependency.py --output validation-output/macos-deps/install-candidate-new
./target/debug/vpngate-auto-proxy mac-dependency --bundle "$PWD/validation-output/macos-deps/install-candidate-new"
```

输出目录必须尚未存在。当前候选已构建，直接核验无需重新构建：

```sh
./target/debug/vpngate-auto-proxy mac-dependency --bundle "$PWD/validation-output/macos-deps/install-candidate-20261012"
```

管理员实际安装尚未执行。今后在用户自己的终端完成系统授权后，安装命令为：

```sh

```

此步骤仅安装该固定依赖；不表示苹果服务可运行。当前会话免交互管理员检查返回需要密码，未尝试获取密码或写入系统目录。
