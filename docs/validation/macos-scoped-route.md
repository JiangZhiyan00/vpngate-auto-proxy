# 苹果作用域默认路由

日期：2026-10-12，中国标准时间。T085 细分自 T057，完成路由组件及已配置业务代际的调用接入。当前没有执行管理员路由写入或真实公网验证。

路由按所属接口安装四版作用域默认项，不更改全局默认路由、系统解析或报文过滤。系统允许按接口作用域区分相同目的地址，且点对点接口可直接作为下一跳，依据[苹果路由手册](https://github.com/apple-oss-distributions/network_cmds/blob/main/route.tproj/route.8)。消息布局取自本机系统开发包与现有系统绑定，独立实现安全字节编解码，没有复制路由工具源码。消息地址按四字节对齐，依据[苹果路由工具的消息接口](https://github.com/apple-oss-distributions/network_cmds/blob/main/route.tproj/route.c)。

入口在任何写入前要求管理员身份、真实控制句柄、仍有效的代际以及吻合的接口地址、状态与最大传输单元。只允许新增本次接口的默认路由；预先存在的同键路由直接拒绝，不接管、不覆盖。新增后查询内核，核对作用域、索引、直接链路下一跳、目的和掩码。每条消息有一秒总截止及通知数量上限，按进程号、序列号、消息类型接收对应回复；其他接口通知不使用路由头解析。所有请求和回复均使用安全字节存储，没有新增不安全代码或依赖。

已配置代际现在先安装路由，再启动业务工作进程；安装失败不启动业务，仍回收直属隧道。正常停止先撤销代际，同时回收业务与隧道，再比对新增时的路由快照并删除。持有的真实句柄保留接口身份。任一消费者回收结果未确认时，保留路由至接口释放，不抢先删除；路由被改动时拒绝删除未知资源。新增确认后若发生撤销，尝试精确回滚并聚合错误；新增回复未确认时不声称拥有该项，停止消费者后由接口释放承担内核自动清理，原生自动清理仍待验证。丢弃对象不执行网络写入。

十一项新增测试覆盖固定消息与本机布局、截断和非法字段、全局或其他下一跳拒绝、真实只读回环查询、普通用户拒绝、新增与重复回收、既有及被替换路由保护、各边界撤销、未确认新增与回滚失败，以及真实普通子进程的启动/退休顺序和路由冲突回收。配置及路由写入使用注入后端；只读查询实际使用系统路由通道。初始事务未实现时两项定向回归失败，完成后通过。

首次完整回归有一项既有代际测试在非阻塞套接字读取关闭状态时返回暂不可读；单项与契约重试通过。已将关闭状态验证改为一秒总截止内等待可读事件，保持读取结果必须为关闭，未放宽登记资源释放和撤销断言。修正后完整回归通过：142 项单元、63 项普通契约；35 项依赖或目标环境测试保持忽略。格式、严格静态检查与锁定构建通过，见[工具证据](macos-scoped-route-tools.json)。

待验证范围：管理员实际新增/删除、地址配置产生的隐式路由和冲突、三个同地址并存接口、管理端点仍走宿主出口、任意公网业务与解析归属、正常网络变化、监督及隧道故障时零直连、宿主基线与自动清理。主服务、特权部署、归属清单及安全重启仍未接通。T057、T058 保持未完成；三十分钟测试继续暂缓。
