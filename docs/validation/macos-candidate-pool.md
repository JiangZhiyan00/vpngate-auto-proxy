# 苹果候选代际池验证

日期：2026-10-13，中国标准时间。任务：T090，属于既有 T057 范围。

已实现特权侧候选代际管理库，接入正式代际启动、低权限出口检测和既有活动工作端类型。公共服务入口、来源控制进程、轮次调度、状态命令和完整恢复流程仍待接入；当前未启用苹果主服务。

## 实现与边界

- 创建候选前核验节点标识、配置摘要、来源存在性与年龄，再用既有本地配置复核入口校验安全尾部、唯一端点及承载。来源时间位于未来、失效或配置改变时拒绝使用。
- 候选所有者先登记再等待就绪。接口配置串行，已就绪代际可以并发检测；候选最多 32 个，活动代际另占一个槽位。未确认回收的代际继续占槽，且阻止创建新的并存接口；现有活动出口不因此主动轮换。
- 只有正式低权限检测成功、代际仍存活，才生成不可复制及不可反序列化的提升凭据。凭据关联池、工作标识、业务代际、配置摘要和单调时钟时间；提升时再次核验当前来源及有效期。已有健康活动出口时拒绝提升其他候选。
- 活动快照使用实际代际撤销令牌。监督结束会撤销该令牌，转发方必须遵守撤销；管理层刷新时清除故障快照。退休、整体停止和池丢弃都先撤销公开引用。整体停止并行等待各代际，等待被取消后可继续回收同一批任务。
- 运行错误与清理凭据独立。直属消费者、检测子进程、路由回收步骤及所属目录全部确认后，失败候选仍可释放槽位，原始错误通过退休诊断返回。路由写入或删除未确认、消费者未回收、目录包含未知材料时保留槽位和归属材料。即使路由写入可能在实际变更前失败，也不凭错误字符串推断没有变更。
- 回收凭据不证明完整宿主基线、外部持有的句柄复制件或安全重启。既有目录清单仍不是完整跨进程启动身份与资源恢复清单。

## 验证

新增十一项普通权限单元回归：候选池八项、清理状态两项、路由不确定状态一项。覆盖来源与配置拒绝、真实管理员前置门槛、槽位反复释放、串行就绪及取消恢复、过期及变更凭据拒绝、健康活动保持、故障旧引用撤销、并行停止与取消恢复、运行失败和未知回收区分、丢弃后继续释放普通描述符。

首次回归发现调用方把已再生配置再次按外部原始配置清洗，安全尾部被正确拒绝；修正为调用既有严格本地配置复核入口，没有放宽危险指令规则。首次和修正后日志均保留。

完整检查：198 项单元及 64 项契约通过，35 项特权或目标环境用例忽略；格式检查、严格静态检查、锁定构建通过。工具摘要与日志摘要见[机器记录](macos-candidate-pool-tools.json)，原始日志位于 `validation-output/macos-pool-20261013/`。

这些测试只验证普通权限资源所有权和编排。测试提升凭据由模块内测试代码注入成功报告，正式入口必须经过独立低权限检测；测试描述符不是原生隧道，不据此宣称完整苹果隔离、降权部署、公网出口或故障防漏通过。
