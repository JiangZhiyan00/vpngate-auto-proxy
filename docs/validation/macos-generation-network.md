# 苹果业务代际网络入口

日期：2026-10-12。对应 T071，属于 T057 的实现增量；后续已接入苹果系统内部工作进程，见[接入记录](macos-verified-worker.md)。

`VerifiedNetworkGeneration` 只能由已核对真实控制句柄的 `UtunCustody` 构造。业务方取得的 `VerifiedNetworkLease` 不公开数字接口索引、控制句柄或出口套接字，仅提供已完成握手的流式连接转发和有界原始解析查询。转发入口可接收正式工作进程的私有套接字。出口目的地和解析服务器均必须是允许的公网 IPv4 且端口非零；仅内部测试构造器允许回环目标。接口绑定与代际操作登记在入口内部执行；撤销后拒绝新操作，正常退休等待登记操作结束后释放控制句柄。流式转发的两端套接字均由登记操作持有，撤销会丢弃它们。解析先使用固定接口数据报，收到截断标志后以同一接口建立流式连接；五秒总截止、查询 512 字节和响应 4096 字节上限由入口强制执行。

测试采用普通权限的真实回环套接字。六项用例验证：截断解析在同一接口完成流式重试，退休后旧引用拒绝联网；进行中的流式转发在退休确认前关闭两端；无效解析材料不创建套接字；等待中的解析被撤销且原数据报本地端口可重新占用；非公网目标在出口创建前拒绝；私有套接字作为工作端接入后完成双向流式转发并由代际撤销。`cargo test --locked`、`cargo fmt --check` 与严格静态检查通过，其中二十九项专用 Linux 特权集成测试按既有条件未执行。

接口只返回原始解析报文；后续苹果内部工作进程在 `src/socks.rs` 接入目标策略、完整 DNS 报文解析和 SOCKS 握手，T072 按限定范围完成。T084 已接通配置监督与业务启动的组合入口，见[记录](macos-prepared-generation.md)；正式公共服务和生产业务路由尚未接通，因此不能据此宣称生产业务、解析与所有网络路径已封闭。进程权限边界、控制通道异常退出后的实际服务状态及安全重启还须后续实现与原生验收。T057、T058 保持未完成；三十分钟测试继续暂缓。

后续 T087 已串联特权代际调用与归属目录，见[启动记录](macos-generation-bootstrap.md)；正式主服务接入与原生验收仍未完成。
