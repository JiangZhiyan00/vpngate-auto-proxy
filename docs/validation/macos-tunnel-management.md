# 苹果直属隧道管理会话

日期：2026-10-12，中国标准时间。T075 按已认证管理会话及普通权限回归范围完成，是 T057 的实现细分，不表示完整苹果后端已经完成。

`src/platform/management.rs` 接收已经接受的私有套接字连接。先通过内核对端凭据核对用户及进程号，必须与调用方仍直接持有的隧道子进程一致；不允许使用历史清单中的裸进程号代替直属子进程身份。监听路径、目录归属、接受连接的总截止及子进程回收仍由正式监督方负责，本模块不根据路径信任对端，也不删除外部路径。

管理会话等待程序报告启动等待，先开启状态通知，再释放本次等待；保留等待标志，后续程序内部重启不得自动复用该代际。仅在释放后收到连接成功状态、有效四版本地和远端地址时发送一次连接确认。此确认只提供下一步核对材料，不代表已通过接口地址、路由、出口或业务解析验证，不得据此发布活动节点。协议依据[正式管理接口说明](https://openvpn.net/community-docs/management-interface.html)，固定版本行为同时核对本地 2.6.23 管理实现。

每条管理记录含换行最多 4096 字节，启动前累计输出最多 65536 字节；启动总预算必须大于零且不超过 120 秒，分段记录不能刷新截止。固定版本流式承载的连接中状态及认证等待状态允许在启动截止内继续；端点必须直接使用已核验四版地址，因此意外进入主机解析状态会拒绝。启动之后持续消费管理输出；通道关闭、异常编码、未知记录、错误或密码请求、重连、退出、再次等待、连接地址变化，以及连接后的其他非连接状态，均终止会话并撤销令牌。调用方主动停止或取消已经运行的监督未来也撤销并关闭管理端，没有脱离监督的后台读取任务。撤销令牌还须由正式监督方连接业务停止和退休路径；本模块尚未接入 T074 或正式服务。

七项普通权限真实套接字回归通过，覆盖分段等待及连接状态、连接前不发布、错误用户及进程在命令前拒绝、连接后重连和退出、重复等待、异常记录与地址、连接地址变化、分段输入的总截止、主动停止及监督任务取消。错误身份测试先实际失败，再加入身份检查及会话实现后通过。
