# 苹果继承私有控制协议

日期：2026-10-13，中国标准时间。T094 是已有 T057 的集成细分；本轮完成私有通道协议与候选池接入，控制子进程正式启动、身份核验和公共主服务尚未完成。

## 权限与操作边界

服务端接收部署方私有交付的已连接本地套接字、固定授权标识、候选池及固定健康设置，不创建公开监听器，不按调用方给定的路径连接管理员服务。部署方仍须核验控制子进程的实际身份、启动关系和描述符交付，协议授权不代替这些部署证据。当前入口仅供后续启动方接入，不单独启用苹果服务。

控制方只可请求存活检查、启动指定节点、等待就绪、出口检测、提升、退休、状态和停止。账户、依赖路径、运行父目录、候选上限、健康设置及特权启动预算均由服务端事先固定，不能通过请求修改；节点材料继续由正式候选池独立验证。

成功检测凭据只保留在服务端，既不序列化也不交付客户端。每次新检测先移除旧凭据，提升时取走唯一凭据并重新检查当前节点与有效期。未验证、过期、变更或不属于本池的代际不能提升。成功提升即启动既有独立健康所有者；健康启动失败会退休该代际，不能留下已发布但未监督的活动出口。

## 通道关联与资源上限

请求和响应均含固定版本、本次授权及严格递增序号；客户端还核对操作类型、工作标识，以及提升响应的节点标识。就绪及提升响应须含非空代际标识和绝对工作端路径。错误响应不携带解析器原始输入，调试输出隐藏授权和节点私有材料。

帧长度上限为一兆字节，拒绝零长度、超限、未知字段、重复字段及截断。空闲通道可持续存活；收到首字节后，余下长度与载荷共用三秒截止，结果交付另有三秒截止。收发缓冲使用清零包装，但该保证仅覆盖帧缓冲，不宣称所有解析后的连接配置内存都已经清零。

客户端克隆共享一个串行通道，一次只执行一项操作。请求截止包含排队及收发；尚在排队时超时不关闭其他正在执行的请求，也不占用序号。开始执行后取出通道，超时、取消、响应归属错误或半帧错误均关闭连接，禁止下次复用迟到响应或半帧状态。停止成功后同样不复用连接。

服务端只允许一项在途请求，操作执行期间仍观察控制方断开；提前发送下一请求也视为会话故障。断开、取消、帧错误或结果无法交付后，先结束控制会话，再撤销并等待全部所属代际。取消就绪、检测或退休等待不丢弃候选池所有者；外层服务等待被丢弃时，原任务继续回收，外层运行时须保持存活。失败与清理确认独立，未知回收仍保留原材料及失败结论。

## 状态与待接入范围

状态响应包含所属工作标识、当前存活及活动状态，以及最多一条健康诊断。通道目前采用请求响应，不推送异步活动状态；下游工作代际的撤销会立即关闭登记业务与解析资源，但控制侧仍须在后续主服务中接入状态刷新、通道终止与本地网关引用撤销。不得将旧状态快照作为永久可用性凭据。

本轮尚未实现低权限控制子进程的启动和启动关联核验、来源请求与轮次接入、公开状态/停止命令、异常重启恢复清单及完整原生验证。不得把同进程测试的授权通道写成已通过真实管理员到低权限控制进程的部署验收。
