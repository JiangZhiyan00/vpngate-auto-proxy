## 实测环境及范围

苹果 ARM64 主机通过本机引擎运行独立 Linux ARM64 受控环境。两种部署路径分别验证：直接启动 Linux 程序、实际 Alpine 3.22 运行镜像。前者仍处于容器内，不能作为 Debian 12 / Ubuntu 24.04 x86_64 原生验收；也不是苹果系统原生服务。

直接启动路径使用已有调试构建，内核为 `7.0.14-orbstack-00380-ga7e0a2dc9535`；容器路径使用发布构建镜像，完整标识及程序摘要保存在原始记录。未启用应用安全模块，保留默认系统调用过滤与禁止新增权限。

客户端为五个独立网络身份：直接启动路径创建五个网络空间和虚拟网卡；容器路径创建五个无额外能力的客户端容器。每个客户端经认证持有十条真实隧道内回显连接，按约一秒间隔往返，任何一轮超过十秒即失败。配置将候选周期缩短为五秒，最多二十节点、并发二；受控来源提供三个不同固定端点，避免用无检测活动的空场景冒充共存。

## 复现与失败行为

先构建程序及已有受控镜像。原生模式只在显式授权的专用 Linux 管理员环境运行，事先准备工具、转发与必要防火墙路径；遇地址池或夹具名称冲突直接失败。

```sh
VAP_NETWORK_TEST=1 scripts/validate-soak.sh --deployment native --clients 5 --connections 50 --duration-seconds 15 --binary ./target/release/vpngate-auto-proxy --output validation-output/soak-native.json
scripts/validate-soak.sh --deployment docker --clients 5 --connections 50 --duration-seconds 15 --output validation-output/soak-docker.json
```

凭据由工具临时随机生成，文件仅属主可读，经私有标准输入传给客户端，不放进命令参数或报告。报告先写本次运行状态，成功并完成清理后原子替换为通过；失败或中断改为失败，不能沿用旧成功报告。本轮已实际在客户端运行期间发送终止信号，确认非零退出、旧报告失效、所有本次容器、网络和数据卷删除。另有三项客户端失败判定回归通过。

需要正式验收时将持续时间显式改为一千八百秒，两种部署分别运行；本轮没有执行。`--case all` 已接入容量工具并传递持续参数，聚合时省略秒数仍会运行长测，暂缓期间应始终指定十五秒。
