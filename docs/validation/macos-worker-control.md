# 苹果内部工作进程的监督握手

日期：2026-10-12。T073 按专属监督通道和普通权限验证范围完成；正式进程启动、降权、路由、生产故障及安全重启仍属 T057 的必要工作。

隐藏工作进程入口在真实控制句柄核验后，调用 `platform::worker::serve`。工作进程先建立私有 SOCKS 监听，再通过继承的专属监督通道发送就绪帧；就绪帧写入成功后才接纳代理请求。启动已取消、监听失败或就绪帧发送失败时，不进入接纳循环，并清理自己创建的监听。现存文件冲突时拒绝启动，不删除原文件。

就绪帧为固定四十字节：版本 `VWR1`、十六字节授权标识、十六字节业务代际、四字节大端接口索引。退休帧采用相同布局与版本 `VWT1`。监督方使用 `wait_ready` 和 `wait_retired` 接收，核对授权、索引和非零代际；退休还须与之前就绪的代际一致。每次完整接收和发送均有三秒总截止，分段到达不延长截止。这个通道不执行任意命令；对端关闭、读取错误或任何输入都会取消工作进程。

工作进程停止接纳后，撤销代际、终止并等待请求任务、等待登记资源及持有句柄释放、移除私有监听，随后才发送退休帧。对端已消失时，退休帧发送失败不影响本地回收。就绪只表示私有工作端已准备好接受出口验证请求，不能替代隧道出口验证；退休帧也不能替代直属子进程退出回收和启动身份核对。

八项普通权限真实套接字测试覆盖就绪后监听可访问、未完成 SOCKS 请求及代际测试句柄在退休确认前释放、原路径冲突不发布就绪且保留原文件、监督方启动前及就绪后关闭的清理、就绪发布失败清理、错误版本/授权/索引/零代际拒绝、错误退休代际拒绝，以及部分确认帧的总截止。两项真实单文件子进程回归覆盖伪造控制句柄失败且监督通道不出现就绪帧，以及交接前控制通道关闭后及时失败退出。

已执行构建、完整 Rust 测试、格式和严格静态检查，以及 `python3 -m unittest scripts/test_macos_verified_worker.py`，均通过。三项环境专用契约与二十九项 Linux 特权集成测试仍按既定条件跳过；本轮不创建原生隧道，不运行三十分钟测试。
