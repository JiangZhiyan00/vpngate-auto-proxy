# 苹果已配置代际联合监督

日期：2026-10-12，中国标准时间。对应 T084，细分自 T057。

新增已配置代际驱动，将直属隧道的严格材料、地址配置监督与低权限工作进程启动入口串联。监督方保留控制句柄复制件至两侧回收均已尝试；工作进程通过既有私有通道获得独立复制件。业务启动期间持续轮询停止、撤销和隧道故障，取消后仍等待启动流程显式回收，避免直接丢弃派生中的进程。工作进程就绪后再次核对身份、直属进程与撤销状态，再交付私有入口和代际身份。

就绪材料丢弃会撤销整代际；业务意外退出或隧道监督结束也触发撤销。结束时同时尝试业务退休与隧道回收，聚合两侧错误。一侧失败不会跳过另一侧；等待被外部取消时关闭通道、撤销令牌并触发直属子进程终止，但不能把取消本身当作显式回收成功。

九项新增测试覆盖正常停止、材料丢弃、启动中取消与隧道失败、错误就绪身份、就绪接收方退出、业务强制退出、双侧无响应、组合未来取消，以及配置缺失、失效材料和提前停止。配置层使用普通套接字注入；双消费者测试实际派生普通权限子进程并核对回收和最后描述符释放。测试不证明真实控制接口、管理员地址写入或身份降权。

验证：全部默认测试通过，131 项单元与 63 项普通契约通过，35 项依赖或目标环境测试保持忽略；格式、严格静态检查及锁定构建通过。最初阶段驱动未实现时定向测试失败，完成实现后通过。本轮没有新增依赖或不安全代码；固定依赖摘要沿用已有记录，未重复运行显式依赖检查。机器可读结果见[工具证据](macos-prepared-tools.json)。
