# 苹果低权限候选出口检测

日期：2026-10-12，中国标准时间。T089 细分自 T057。苹果代际句柄的 `check_exit` 现已接入原有真实出口检测器；请求通过独立低权限检测子进程执行，并使用该代际私有工作端。此增量提供候选及活动健康检测调用链，候选调度、结果有效期、活动提升和公开服务仍未接入。

特权方只核对配置、账户、自身受保护安装记录及已知私有工作端，随后以同一可执行文件的隐藏 `mac-probe` 命令派生直属低权限子进程。控制套接字对与派生进入既有同步保护，环境清空，明确设置用户及主组。子进程不获得隧道控制句柄，只获得自己的专属控制通道；它再次拒绝管理员用户或组，核对业务目录 0750、私有套接字 0600 及账户归属，再调用既有检测器。真实管理员降权、安装部署及公网隧道仍待原生验证。

内部材料采用固定第一版、随机授权和业务代际身份。双向帧由四字节大端长度和有界结构化材料组成，上限 65536 字节，拒绝未知字段。地址只接受无凭据的网页协议；至多 32 个地址、每址 4096 字节、合计 32768 字节，最多 32 次请求，实际请求总预算为 1 毫秒至 120 秒。预算向下取整为毫秒，不扩大调用者截止。这些内部安全上限须在后续苹果配置接入时明确诊断，不静默截断。已有默认候选十秒、活动五秒、三次尝试满足上限。单次机会分配、证书核验、重定向和响应判断继续复用现有检测器，不引入特权方网页请求或系统代理回退。

子进程启动材料读取与结果发送各有三秒截止；特权方结果交换截止为请求预算加三秒，回收另有两秒正常退出及两秒强制回收上限。结果核对授权、业务代际、尝试次数、状态、失败类型及耗时，只有成功报告并确认直属子进程正常退出及回收后才返回成功。失败报告、无效材料、超时或撤销在等待回收前撤销该代际；回收错误继续返回，不用撤销通知冒充回收完成。停止或外层检测等待被丢弃时，专属任务继续关闭控制端并回收本次子进程。外层运行时仍须保持存活，整体退出与安全重启未由此证明。

代际句柄使用保存的正式业务身份和私有工作端调用此组件。检测前未就绪或已撤销拒绝，失败及部署拒绝撤销代际，成功后再次核对所属代际仍存活。它不会据成功报告自动发布活动出口，也不会自行删除代际目录；上层仍须明确完成代际停止与回收。

所有检测活动都登记到代际所有者，回收凭据由实际直属子进程状态更新。等待被取消后，登记仍由后台回收任务持有；代际显式停止释放就绪材料后，还须等待所有已登记检测完成。登记中存在无法确认回收的凭据时，停止持续报错，不用计数归零当作成功。等待可被取消后继续。正式检测子进程以受保护主程序目录为工作目录，不把代际材料目录作为自己的工作目录；这不能替代对子进程的明确回收。
