# 苹果控制接口创建组件

日期：2026-10-12，中国标准时间。T080 按接口创建组件、普通权限回归及原生诊断工具准备范围完成，属于 T057 的实现细分。管理员实际创建尚未执行，地址配置、正式启动流程接入及完整后端均未验收。

## 实现范围

`src/platform/interface.rs` 的创建入口先检查真实和有效用户均为管理员，再读取内核接口清单并创建本次控制连接。调用方不能指定已有接口、控制器名称或控制单元；固定查询苹果隧道控制器，逐次请求 1 至 255 的明确单元。只在连接阶段收到明确占用错误时重试；控制器查询、权限及其他错误直接返回。每次失败由拥有类型关闭本次描述符，不执行按名称销毁接口的命令。

接口名称通过真实控制连接的套接字选项取得，索引通过内核名称查询取得，再交由既有控制句柄验证器核对。创建入口拒绝启动前已有的名称或索引，以及非点对点、回环、已有四版地址或无法查询初始状态的接口。返回前再次从持有句柄复核身份；不推导控制单元、接口名称后缀及索引之间的关系，也不调用该控制套接字不支持的本地地址查询。

`UtunCustody::revalidate` 使用受保护复制件核对实际连接；拒绝不会关闭调用方的原件。返回的句柄可供已有直属隧道父进程借用，并移交业务监督方，但本轮尚未将创建、管理、业务启动和资源清单组成完整特权流程。执行时关闭标志在连接前设置；苹果创建套接字和设置该标志为两个系统调用，调用期间不得并发派生子进程，正式流程须落实这一串行约束。

内核控制协议依据[苹果官方说明](https://developer.apple.com/library/archive/documentation/Darwin/Conceptual/NKEConceptual/control/control.html)，系统调用通过已有固定版本依赖的安全封装完成，仅启用其控制器查询特性，没有新增依赖版本。锁文件摘要与现有第三方声明清单一致。本项目源码没有新增不安全代码或复制系统实现。

## 地址材料仍待接入

现有管理状态的本地地址为隧道地址，远端地址为承载连接的服务器地址，后者不能当作虚拟接口的点对点地址，见[管理协议字段说明](https://openvpn.net/community-docs/management-interface.html)。本轮不据此猜测点对点对端或子网掩码。

固定版本还提供接口启停环境通知，见[固定版本管理选项](https://raw.githubusercontent.com/OpenVPN/openvpn/v2.6.23/doc/man-sections/management-options.rst)。本地已核对该版本 `manage.c` 的环境帧输出、`init.c` 的启停通知及 `tun.c` 的地址环境设置：点对点对端和子网掩码分别通过不同字段提供。下一步须实现有界帧解析、必要字段唯一性和拓扑校验，并与已认证管理连接、本次真实接口及连接材料交叉核对，然后才允许配置所属接口。尚未启用该通知选项或改变既有管理解析行为。

## 本轮验证

八项新增普通权限单元回归通过：权限前置拒绝；占用重试时失败描述符关闭而成功描述符保留；查询占用及无关错误不重试；全部单元占用时有界停止并释放每次句柄；既有名称、索引、地址及异常标志拒绝；真实内核接口清单；真实控制套接字初始化与控制器查询；无关数据报套接字复核拒绝且原件保持可用。权限拒绝回归在实现前实际失败，完成后通过。

控制器查询回归没有调用连接操作，查询前后内核接口清单一致，不能算管理员接口创建证据。探针的普通权限执行明确返回失败，检查项与接口列表为空，接口清单未变化。原始输出见 `validation-output/macos-interface-ordinary-refusal.json`，摘要收录于[工具记录](macos-interface-tools.json)。

完整默认检查：86 项单元、63 项普通契约通过，35 项默认忽略用例未执行。十五项既有句柄实验、启动入口和严格工作进程脚本回归通过。脚本首次调用缺少脚本目录导致导入错误，补齐模块搜索路径后全部通过，未将该次导入失败计为验证通过。格式、全目标严格静态检查、锁定主程序和探针构建通过。

## 待执行的原生诊断

独立诊断入口 `examples/macos_interface_probe.rs` 使用上述真实创建组件，创建两个未配置四版地址的接口，核对并存身份，释放第一个后确认第二个仍存活，最后释放第二个并等待接口清单恢复。失败也仅释放本次持有的句柄，禁止删除未知接口；每次生命周期确认限时三秒。

本轮免交互管理员检查仍提示需要密码，未运行下列命令，未创建接口：

```sh
sudo ./target/debug/examples/macos_interface_probe
```

这是独立诊断程序，不属于正式交付可执行文件。即使命令通过，也只证明该创建组件的接口生命周期；输出始终保留 `native_tunnel_validated=false` 和 `full_macos_backend_validated=false`。它不配置地址或路由，不启动加密隧道、业务工作进程或公共服务，不替代管理员保护部署、静态候选隧道、公网路由、完整故障阻断和安全重启验收。三十分钟测试继续暂缓，T057、T058 保持未完成。
