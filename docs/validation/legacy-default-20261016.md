# Linux／Docker 默认旧算法兼容修订

日期：2026-10-16，上海时区。根据用户实际部署反馈调整，尚未提交或发布。

Linux 原生省略 allow_legacy_vpngate_crypto 时默认 true，容器环境省略或空字符串也默认 true；显式 false 始终关闭兼容。苹果原生默认仍为 false。仅改变应用默认策略，不改变底层严格解析接口及既有算法组合、脚本、外部文件、压缩、证书和端点约束。

先运行新增默认值断言，复现容器默认及空值两项失败；修改后 Rust 完整适用回归 409 项通过、39 项按适用条件忽略、零失败。已有旧算法严格拒绝／兼容接受、固定组合拒绝混搭及缓存撤销重验用例继续通过。离线部署 Python 定向 14 项通过，覆盖省略默认及显式 false；格式、clippy 全目标警告门禁和差异空白检查通过。

Rust 原始日志为 validation-output/legacy-default-rust-tests.log，不纳入源码提交。当前普通测试运行于苹果宿主，容器环境转换直接执行；Linux 原生默认分支由目标系统条件定义，真实最终 Linux 镜像仍须重新构建及验收，不能据普通测试声称已完成该目标门禁。

用户已有配置中的显式 false 不会自动修改，已发布镜像默认值也不会改变。功能 003 十分钟容器验收的镜像／程序摘要早于本修订，保留为历史候选证据，不能用于最新代码发布。真实宿主初始化及强制 AppArmor 门禁继续保留未完成。
