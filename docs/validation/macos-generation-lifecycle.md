# 苹果代际任务所有者

日期：2026-10-12，中国标准时间。T088 细分自 T057。正式主服务接入前，新增不可复制的 `MacGenerationHandle`，直接调用既有特权代际启动链，并同时拥有就绪材料接收端、已交付材料、持续监督任务及取消令牌。

`spawn` 只创建本进程内监督任务，管理员身份、部署、账户和真实接口门槛继续由原启动链核验。`wait_ready` 成功只表示可以通过私有工作端发起验证；入口没有新增跳过出口验证的活动提升接口。未就绪、已撤销或监督已结束时，路径、代际及并存材料入口均拒绝返回。上层仍需将它接入已有来源、候选排序、出口验证、健康检查和活动管理，不能把句柄存活当作节点可用。

取消就绪等待不丢弃监督任务，同一所有者可继续等待同一次启动。显式停止先取消，再释放自身持有及排队中的就绪材料，最后等待原监督任务完成；这样不会由外层多保留的控制句柄阻碍接口释放。停止等待被取消后，任务仍保存在原对象中，重试继续等待同一任务，完成结果及回收错误可重复查询，不重新派生或重复执行回收。启动链的具体部署拒绝或回收错误保留在结果中。

所有者被丢弃时取消并释放材料，但不强行取消正在执行联合回收的异步任务。外层运行时必须保持存活；显式停止并等待才能获得回收证明。监督任务转交材料时保留撤销守卫，正常结束、错误或异常展开都会使已交付令牌失效，即使上层未再次轮询。该令牌可供后续活动连接编排接入，当前仍未连接公开代理入口。运行时整体销毁、主进程崩溃和安全重启不能由进程内守卫证明。
