# 工作代际撤销原型

记录日期：2026-10-12，中国标准时间。

## 问题与本轮范围

[原生索引复用实验](macos-index-reuse.json)已确认：旧数字索引能在复用后把新连接送到另一个远端。因此只传递接口名称或索引不足以表示出口身份。

本轮新增 `src/platform/generation.rs`，只验证进程内的操作登记、不可逆撤销与等待释放。该模块不创建隧道、不管理子进程，尚未接入生产服务；既有苹果 `InterfaceScope` 仍是可复制的底层索引类型，不能因此宣称代际隔离已完成。

## 已实现的原型语义

- 监督方持有不可复制的 `WorkerGeneration`，业务方只持有可复制的 `WorkerLease`。每次创建使用新的随机身份，与数字接口索引分离；随机身份仅用于区分代际，不充当认证凭据。
- `revoke` 永久取消该代际；已撤销引用不能构造新操作。新代际不会重新启用旧引用。
- `execute` 在读锁保护下运行登记操作，取消分支优先；操作的异步体及其资源先释放，再释放登记锁。
- `retire` 先撤销，再获取写锁等待已登记操作全部释放，最后返回包含本代身份的完成记录。等待中途取消不恢复访问；可继续等待，但不能把超时当成回收完成。
- 丢弃监督对象会触发撤销，但不等待释放，因此不能把对象析构作为删除接口的许可。

取消与锁的使用依据：[取消令牌正式文档](https://docs.rs/tokio-util/0.7.20/tokio_util/sync/struct.CancellationToken.html)、[异步读写锁正式文档](https://docs.rs/tokio/latest/tokio/sync/struct.RwLock.html)。取消通知本身不等于操作释放完成，因此原型额外等待登记锁归还。

## 必须保持的调用约束

登记操作必须拥有其套接字和资源，取消时同步释放。不得返回可继续发起网络请求的句柄、将资源存入外部容器，或派生未登记的后台任务。通用异步执行接口无法自行强制这些规则；后续工作进程必须封装所有业务连接、域名解析和检测操作，避免暴露底层索引与套接字。

撤销不能中断正在执行且不让出控制权的同步代码；此时回收确认会等待。外层监督必须施加总清理时限并回收所属子进程，不能在等待失败时直接释放接口并启动替代工作进程。本轮没有实现跨进程回收确认，原型完成记录也不能代替操作系统进程退出证据。

## 验证结果

先运行缺少撤销语义的基线实现，六项测试中五项按行为断言失败：旧引用仍执行、监督丢弃未撤销、退休未撤销及两项活动操作无法取消。实现后新增等待取消回归，共七项通过：正常结果及错误保留、旧克隆不构造操作、真实流式套接字在确认前关闭、新旧身份隔离、监督丢弃撤销、双线程十六项登记操作全部释放，以及取消退休等待后仍拒绝旧引用。

```sh
cargo test --locked --test contracts generation::
cargo test --locked
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
```

本机十三项单元、五十一项普通契约通过；三项特权契约和二十九项特权集成用例明确忽略，不能计为通过。格式及严格静态检查通过。未运行三十分钟测试，未进行新的管理员网络实验。

## 后续验证要求

1. 将代际身份绑定到独立业务工作进程及其私有控制通道，授权不能只依赖请求中的身份字符串。
2. 撤销活动入口后取消全部旧业务、解析及检测任务，确认旧工作进程退出，再释放本实例接口；失败时保持拒绝并报告清理错误。
3. 覆盖隧道进程异常退出、外部接口删除或重建、绑定与发送之间的竞争；证明旧业务不会借新接口发出请求。仅周期查询接口存在不够。
4. 在实际索引复用后检验旧引用拒绝、新代际业务和解析归属、候选不受影响，以及超时或强制退出后的资源归属和宿主基线。

上述进程级隔离、防直连及异常恢复尚未实现或验收。T057/T058 保持未完成，不接入生产苹果转发路径。

## 独立受控工作进程增量（2026-10-12）

新增 `examples/macos_generation_worker.rs` 与 `scripts/macos_generation.py`，并接入 `--case generation`。工具使用上一节代际组件控制拥有真实套接字的登记操作，并要求正常退出确认先于接口释放；替代工作进程接收旧代际请求时拒绝，新代际可以完成双向回显。

工作进程只读取继承管道，不创建对外管理端口；命令上限 4,096 字节、队列上限四项，只接受固定目标的单个保留操作与本代撤销。读取使用专门的普通线程，避免不可取消的异步标准输入读取拖延退出，依据[异步标准输入文档](https://docs.rs/tokio/1.50.0/tokio/io/fn.stdin.html)与[标准线程文档](https://doc.rust-lang.org/std/thread/index.html)。网络资源由异步操作持有，主线程退出前已经等待释放；输入线程不拥有业务套接字。

九项真实工作进程测试覆盖正常回显和退出、旧代际探测与撤销拒绝、真实替代进程身份变化、父管道关闭、额外目标字段、超长帧、重复操作拒绝及活动连接释放；七项实验顺序/失败清理回归通过，既有十项复用回归通过。工具准备证据见[记录](macos-generation-tools.json)，原生操作见[计划](macos-native-plan.md)。

这些结果仍是工具、回环进程和远端夹具验证，真实索引复用后的受控撤销结果待用户终端执行。当前工作进程只实现受控回显，生产解析与代理未接入；外部重建竞争与进程权限隔离尚未收口。即使下一项通过也不标记完整索引复用隔离通过，T057/T058 继续未完成。
