# 苹果直属隧道配置监督接入

日期：2026-10-12，中国标准时间。对应 T083，属于 T057 范围内的组件串联，不收口完整苹果后端。

## 已实现的路径

`ManagedMacTunnel::start_for_configuration` 复用既有管理员保护路径、直属进程、私有管理连接及真实句柄交接流程，并显式选择接口通知模式。该模式经过本项目隐藏串行入口传至固定外部隧道程序，启用 `--management-up-down`；原有 `start` 与隐藏入口缺省模式继续兼容旧连接状态监督。旧联合监督入口拒绝接收通知模式隧道，拒绝时仍等待两侧消费者回收。

`ManagedMacTunnel::run_configured` 消费本次原始控制句柄与通知模式隧道，在同一个持续轮询的未来中依次完成：

1. 核对通知模式及接口归属，从原件复制并校验真实控制连接，使用已认证严格管理入口等待完整拓扑与连接状态。
2. 保留原始句柄；取得完整且未撤销的同接口材料后调用已有地址配置组件。材料等待及发布前使用本阶段启动截止。
3. 同步配置返回后再次轮询管理会话、直属进程、停止与撤销信号，先处理已到达的故障，再交付配置材料；配置返回后超过截止也拒绝交付。同步系统调用本身不宣称可被异步截止强制中断。
4. 交付之后继续监督同一个直属进程与管理未来；停止、进程退出、会话异常或材料撤销均关闭管理连接、撤销同一令牌并限时回收隧道及所属端点。

正常错误路径中的未交付材料、接收队列及父方原件保留至直属进程回收尝试结束。地址配置失败也遵守这一顺序。取消监督未来则由守卫撤销、关闭管理连接并触发直属子进程终止；取消本身仍不等同于已经完成等待回收。

已交付 `ConfiguredMacInterface` 持有配置材料。丢弃尚未交接的包装会撤销其管理会话；拆出材料继续沿用原撤销令牌，过期材料拒绝拆出。后续路由和工作进程须继续由该令牌及外层生命周期监督。

并存配置使用已核验材料的复制件。复制前后检查撤销、核对真实句柄，沿用原身份和原令牌；配置结束后释放复制件，避免让长期配置监督借用其他代际的材料。仍须由未来的外层编排在全局停止时有序撤销候选与活动代际。

## 本轮验证

新增十项普通单元测试，扩展一项既有联合监督回归：

- 配置回调成功之后才交付材料，正常停止后直属进程回收且端点删除。
- 配置失败、接收方关闭、启动等待超时及启动前停止，不发布材料并撤销、回收。
- 管理故障早于配置或在同步配置期间到达，均阻止交付；后者验证配置返回后的管理轮询。
- 配置材料丢弃触发监督退出，无需额外停止信号。
- 中止已运行监督未来后令牌撤销；在有界等待内确认真实测试子进程退出，接收方仍保有材料时资源继续持有。
- 过期或错误接口材料不得进入配置回调；包装交接保持同一令牌，未核验普通套接字不能作为并存复制件。
- 公开配置监督入口拒绝旧模式和无效控制句柄，仍回收真实子进程；通知模式实际传到本项目测试子进程。
- 固定程序通知参数仅在明确模式下启用；旧联合监督拒绝通知模式时同时回收业务与隧道。

阶段驱动测试使用真实普通套接字与真实直属子进程，注入受控配置回调和材料，不冒充真实控制接口或管理员地址写入。严格管理解析与地址驱动的独立证据分别见[拓扑材料](macos-topology-material.md)和[地址配置](macos-address-configuration.md)。

先执行有效阶段回归，在驱动尚未实现时失败；首次实现后的回归因测试套接字缺少读取超时阻塞，已终止该测试进程、确认其子进程退出并清理本轮夹具目录。补上有界读取后全部通过；中间失败不计作成功证据。

最终完整检查：122 项单元、63 项普通契约通过；默认忽略三项依赖单元、三项特权契约及二十九项集成，共三十五项。另显式执行固定候选的三项依赖检查全部通过，不重复计入普通单元数量。格式、全目标严格静态检查及锁定构建通过。

固定静态候选摘要核对后，实际执行显示密码算法命令并附加通知参数，程序正常接受且返回算法清单；此检查不建立隧道。候选二进制摘要为 `7619ae9d2fd7592bb834ce8bb54b790aeb2a7e7af7417caab8c08b5353d23a45`。本项目当前构建的原有与新通知隐藏入口均以普通用户实际执行，确认在文件或网络操作前因管理员前置拒绝。本轮未重复脚本检查。

主要复现命令：

```sh
cargo test --locked --lib platform::tunnel::configuration
cargo test --locked --quiet
cargo fmt --check
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked
```

三项显式依赖检查仍需指定已核验候选路径，方式见[拓扑材料记录](macos-topology-material.md)。通知参数含义核对固定 2.6.23 源码的 `doc/man-sections/management-options.rst`，版本与原文来源见[依赖记录](macos-dependency-install.md)。
