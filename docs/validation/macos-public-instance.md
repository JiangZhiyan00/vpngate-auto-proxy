# 苹果公开状态、停止与实例所有权

日期：2026-10-13，中国标准时间。T098 是既有 T057 的实现细分，持久崩溃恢复和管理员原生整体验收仍未完成。

特权父进程在受保护父目录下排他创建本次公开运行目录，取得操作系统独占实例锁，绑定 `control.sock`，再把监听描述符作为标准输出继承给受保护程序派生的低权限控制子进程。子进程在身份、环境、目录和授权握手完成前不接受公开请求；确认后，公开状态读取来源协调器的同一状态通道，公开停止先返回实例标识与停止预算，再撤销活动引用和网关。

低权限进程收到停止后，通过私有控制通道显式请求特权侧关闭候选池并等待确认，随后结束来源协调、管理监听和网关。父进程只在候选池及直属控制进程均已回收后清理身份材料和公开运行目录。控制套接字、实例锁和目录均记录设备号及节点号；未知内容或路径替换会拒绝清理并保留现场。创建过程中归属失败只回收本次新建且仍为空的目录，既有目录不会被接管。

三项新增普通权限回归覆盖：继承公开监听器后的状态与停止往返、停止后特权关闭确认及直属回收；操作系统独占锁、权限和精确节点清理；创建失败回滚与既有目录保留。连同上一阶段控制进程用例，本模块共十三项相关回归通过。完整结果为 270 项单元、70 项契约，36 项目标环境或特权用例保持忽略；格式、严格静态检查和锁定构建通过。机器记录见[工具结果](macos-public-instance-tools.json)，详细日志位于 `validation-output/macos-public-instance-20261013/`。

本轮尚未把普通 `run` 命令切换到苹果后端，因为公开配置还没有声明固定依赖清单、受保护运行父目录及明确低权限账户。也未实现崩溃后的持久资源清单和安全重启；当前发现既有运行目录会拒绝接管。管理员跨账户正向运行、真实隧道、公开代理出口、双承载故障和宿主基线仍须完成，不能由普通权限夹具替代。
