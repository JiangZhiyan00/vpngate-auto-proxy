# 故事一：受控启动与代理验收

日期：2026-10-10，中国标准时间。任务 T024 已完成，真实局域网设备认证访问及拒绝场景均已取得证据。

## 环境与复现

苹果 ARM64 主机上的独立 Linux ARM64 测试容器，Debian 12、Rust 1.90.0、受控 TCP/UDP OpenVPN 服务及 HTTP/DNS 目标。测试资源位于容器私有网络空间；使用测试镜像 `vpngate-auto-proxy-fixture:local`。

容器只挂本项目源码与编译缓存，源码只读。删除默认能力后按网络契约添加所需能力，挂载 TUN、设置容器自身 IPv4 转发、启用禁止获取新权限。未使用全特权、宿主网络或宿主命名空间。

在已准备依赖与权限的专用 Linux 测试环境执行：

```sh
VAP_NETWORK_TEST=1 tests/fixtures/run-us1.sh
```

脚本创建独立临时夹具目录、启动受控来源和节点，以单线程显式执行全部特权集成测试及代理契约测试，最后清理自己启动的夹具。缺少依赖或权限直接失败，不把忽略的用例报告为通过。名称冲突时拒绝启动且不删除既有网络空间，已在独立容器验证。

## 局域网验收发现的空闲保活缺陷

用户另一台电脑首次访问返回代理连接失败；本机复测同样失败。夹具日志确认服务器因空闲保活截止断开隧道：配置过滤了远端保活推送，却未设置本地保活。活动引用尚未实现后续故事的持续健康恢复，未自行重建该隧道。

新增真实空闲三十五秒的集成回归，修复前返回失败，修复后通过。净化配置固定添加 `ping 5`，保留远端推送过滤，不增加业务空闲超时。2026-10-10 15:20（中国标准时间）重跑全部故事一受控测试：9 项特权集成与 3 项代理契约全部通过，没有忽略项；首次数字地址请求 450 毫秒，域名请求 625 毫秒。本机 13 项单元与 25 项普通契约通过，格式和严格静态检查通过。

临时局域网入口已使用修复后的程序重建。用户提供另一台真实 Linux 电脑重试输出，正确凭据请求返回 `HTTP/1.0 200 OK`，响应时间为 2026-10-10 15:21:39（中国标准时间），`Content-Length: 7`。随后同一设备的错误密码请求返回 `User was rejected by the SOCKS5 server`，无凭据请求返回 `No authentication method was acceptable`；两者均未建立代理目标连接。真实设备的认证访问及拒绝场景验收通过。用户未粘贴正文，不将正文内容记为实测证据。本次初始失败保留为缺陷及回归记录。

验收完成后已正常停止并删除临时容器 `vap-lan-validation`，关闭宿主 `10.1.101.202:21080` 映射入口，并删除本地临时凭据及启动参数文件。临时密码不再用于后续部署，文档不保存其值。
