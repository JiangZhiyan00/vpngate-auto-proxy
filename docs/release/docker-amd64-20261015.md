## 能力实验结论

生产代码的静态能力预检保持原样。独立副本只在能力核验实验中跳过静态白名单，由内核和实际操作判定失败，实验镜像不作为发布镜像。移除 NET_ADMIN 或 SYS_ADMIN 导致网络空间预检失败；移除 SETUID/SETGID 导致降权失败；移除 KILL 导致退出回收失败；移除 CHOWN/FOWNER 导致私有目录操作失败；移除 DAC_OVERRIDE 导致工作资源回收失败。SETPCAP 的缺失可能仍允许业务请求，但真实隧道进程的能力集合不再满足契约，因此不能删除。

实验环境是本机 ARM64 Docker 引擎上的 Linux amd64 模拟运行，未强制实施 AppArmor。云端已验的九项能力与安全策略不因本次实验放宽或缩减。此结果不替代 Linux 原生部署矩阵。
